# 上市公司深度分析框架（keeper 实验版）v1.0

> 本 skill 是生产 `company-analysis` skill 的**简化实验版**，专为 keeper 独立实验环境设计。
> 与生产版的核心差异：**数据源用同花顺 IWENCAI，不用 mx MCP**（mx MCP 有积分配额限制，不适合反复实验）。
> 其余骨架、输出铁律、结构规范与生产版保持一致，保证实验结论可迁移回生产。

## 触发条件

用户要求对某上市公司进行"公司分析 / 深度分析 / 基本面分析"时调用本框架。典型触发："对XXX上市公司进行公司分析（keeper）"。

## 数据获取（keeper 专用：同花顺 IWENCAI）

**禁止调用任何 mx-ds-mcp 工具**（keeper 环境无 mx MCP）。改用以下**同花顺 i问财** skill
（均在 `~/stock_research_agent/skills/`，依赖 `IWENCAI_API_KEY` / `IWENCAI_BASE_URL` 环境变量）：

| 需要的数据 | 使用的 hithink skill | 示例查询 |
|-----------|---------------------|---------|
| 行情 / 涨跌 / 资金流向 / 技术指标 | `hithink-market-query` | `{股票} 近10个交易日涨跌幅 换手率 主力资金流向` |
| 财务指标（营收/净利/ROE/负债率/现金流/毛利率） | `hithink-finance-query` | `{股票} 2023 2024 2025 营业收入 净利润 毛利率 ROE` |
| 股本/股东/实控人/股东户数 | `hithink-management-query` | `{股票} 股东户数 前十大股东 实控人` |
| 估值（PE/PB/股息率） | `hithink-market-query` 或 `hithink-basicinfo-query` | `{股票} 市盈率 市净率 股息率` |
| 主营业务/经营数据 | `hithink-business-query` | `{股票} 主营业务构成 主要产品` |
| 事件（增减持/公告） | `hithink-event-query` | `{股票} 最近 减持 增持 公告` |
| 行业数据/排名 | `hithink-industry-query` | `{股票} 所属行业 景气度` |

调用方式（标准）：
```bash
python3 ~/stock_research_agent/skills/hithink-<name>/scripts/cli.py --query "<自然语言问句>"
```
数据不足的项明确标注"数据缺失（keeper 实验数据受限）"，不做无依据推测。

## 输出铁律（优先级最高，所有分析点必须遵守）

1. **固定骨架**：报告必须严格按下方"固定报告骨架"输出，章节名称、顺序、层级不得增删改。开头统一为"一句话定位 + 总体结论"。
2. **散文先行 + 结构化展开**：每个分析点（章节或子项）先输出**综合总结**（平实散文一段，含未来瞻判断），再按"输出结构规范"用 bullets 展开。禁止把结论堆成无层次的大段文字。
3. **过程不省略**：每个结论要展开因果链条：**谁做了什么动作 → 带来了什么结果 → 接下来可能怎样**。基础股市/财务术语（杠杆、融资盘、游资、主力、毛利率、ROE 等）直接使用，不做白话翻译。
4. **结论导向，不要过程**：输出分析结论，不是分析过程。每个子项最多点缀 1-3 个关键数据，且用语言描述（"毛利率连续两年提升至 26%"），不堆数据。
5. **数据展示需过滤**：任何指标都必须是"经分析后值得展示"的指标，并尽量给参考系（同比/环比/往年对比）。
6. **前瞻性**：每个分析点必须包含前瞻/预测判断（1-2 句，点到为止）。
7. **缺失处理**：某项数据不可得时标注"数据缺失"，不做无依据推测；预测性结论须说明依据。
8. **简洁**：语言简洁、不重复、不赘述。
9. **文字格式规范**：全文用加粗/斜体区分内容类别：**加粗**=核心结论/关键数据、*斜体*=前瞻/外部引用/缺失、⚠️=风险、✅=积极信号。

## 固定报告骨架

```
## 〇、一句话定位
## 〇、总体结论（2-4 段，每段=总结句+知识点 bullets）
## 一、公司今日盘面分析
   - 当前表现
   - 资金动向
   - 融资融券与筹码博弈
   - 机构成本参考
   - 涨跌归因
   - 行情总结与策略思考
## 二、公司基本面分析
   - 业务与发展
   - 行业面
   - 盈利模式
   - 财务面（含近3年趋势表）
   - 人力资源面
## 三、综合前瞻判断
## 附：数据缺口说明
---
*免责声明：本报告由 keeper 实验环境自动生成，数据来自同花顺问财，仅供实验研究，不构成投资建议。*
```

## 输出结构规范（两层结构）

每个章节一律为：
```
### X. 章节名
**综合总结**：一段散文（含 1-2 句前瞻）
- **子项标题**：1-2 句结论（含 1-3 个关键数据）
- **子项标题**：1-2 句结论
...
```

总体结论分 2-4 段，每段采用"**总结句 + 知识点 bullets**"：
```
（总结句：总判断 1-2 句，加粗核心结论）
- **知识点**：一个结论点（每个 bullet 一句话，含关键数据）
- **知识点**：...
```

## 与生产版 company-analysis 的差异（保持一致以便迁移）

- ✅ 骨架、输出铁律、结构规范、格式规范与生产版一致。
- ⚠️ 数据源从 mx MCP 替换为同花顺 IWENCAI（keeper 实验无配额）。
- ⚠️ 删去了生产版中依赖 mx 专属语料的部分（如研发领军人物 rd-leaders 语料联动）；
  如需，keeper 环境可用 IWENCAI 检索替代。
