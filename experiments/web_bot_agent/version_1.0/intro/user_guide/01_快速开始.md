# bot_search API 使用说明书 — 快速开始

## 系统概述

bot_search 是一个基于本地 LLM 的智能搜索与文章处理工具。支持两种模式：

- **segments 模式**（默认）：将文章按主题分组，每组附带要点、概括和关键字
- **summary 模式**：对每篇文章生成整体摘要、相关摘要和核心要点列表

```
segments 模式: 搜索 → 提取 → 分块 → LLM 分组 → 合并 → JSON
summary 模式:   搜索 → 提取 → 分块 → LLM 逐块概括 → 合并概括+硬合并要点 → JSON
```

## 环境要求

- **Python** >= 3.10
- **Ollama** 已安装并运行（默认 `http://localhost:11434`）
- **本地模型**：`glm4:9b-chat-q4_K_M`（默认，约 6.3GB）
- **系统依赖**：`web-forager` 命令行搜索工具

## 快速启动

### 1. 安装依赖

```bash
cd research/experiments/web_bot_agent/version_1.0
pip install -r requirements.txt
```

### 2. 启动 API 服务

```bash
uvicorn api:app --host 0.0.0.0 --port 8300
```

服务默认运行在 `http://localhost:8300`。

### 3. 发起第一次搜索（segments 模式，默认）

```bash
curl -s -X POST http://localhost:8300/search \
  -H "Content-Type: application/json" \
  -d '{"query": "信创产业 2025", "keyword": "信创", "max_results": 3}'
```

### 4. summary 模式搜索

```bash
curl -s -X POST http://localhost:8300/search \
  -H "Content-Type: application/json" \
  -d '{"query": "信创产业 2025", "keyword": "信创", "mode": "summary", "max_results": 3}'
```

### 5. 轮询等待结果

```bash
# 用返回的 session_id
curl -s http://localhost:8300/poll/s_20250707_143000_...
```

`status` 为 `"done"` 时返回完整结果，为 `"processing"` 时请继续轮询。

### 6. 查看会话状态

```bash
curl -s http://localhost:8300/status/s_20250707_143000_...
```
