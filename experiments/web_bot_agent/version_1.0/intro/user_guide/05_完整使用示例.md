# 完整使用示例

下面演示一次完整的搜索 — 轮询 — 解析结果流程。

## 1. 发起搜索

```bash
curl -s -X POST http://localhost:8300/search \
  -H "Content-Type: application/json" \
  -d '{"query": "国产芯片 替代 2025", "keyword": "国产芯片", "max_results": 3}'
```

响应：

```json
{
  "session_id": "s_20250707_143000_140737354094912",
  "status": "processing",
  "created_at": "2025-07-07T14:30:00+00:00"
}
```

保存 `session_id` 后续使用。

## 2. 轮询等待完成

```bash
# 轮询，直到 status 变为 "done"
curl -s http://localhost:8300/poll/s_20250707_143000_140737354094912
```

如果还在处理中：

```json
{"session_id": "s_20250707_143000_...", "status": "processing"}
```

通常等待 30-120 秒（取决于文章数量和 LLM 速度）。完成后：

```json
{
  "session_id": "s_20250707_143000_...",
  "status": "done",
  "articles": { ... },
  "segments": { ... },
  "elapsed": 45.2,
  "created_at": "2025-07-07T14:30:00+00:00"
}
```

## 3. 用 jq 解析结果

```bash
# 保存结果到文件
curl -s http://localhost:8300/poll/s_20250707_143000_... > result.json

# 查看有多少篇文章
cat result.json | jq '.articles | keys'

# 查看文章标题
cat result.json | jq '.articles | to_entries[] | {id: .key, title: .value.title, segments: (.value.segments | length)}'

# 查看所有分组要点
cat result.json | jq '.segments | to_entries[] | {seg: .key, point: .value.point}'

# 查看文章 #1 的分组
cat result.json | jq '.articles.a_01.segments[]'

# 查看某篇所有分组的要点和概括
cat result.json | jq '.segments | to_entries[] | select(.key | startswith("a_01")) | .value.point'
```

## 4. 获取分组原文

```bash
curl -s -X POST http://localhost:8300/segment \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "s_20250707_143000_...",
    "article_id": "a_01",
    "segment_id": "s1"
  }' | jq '.text[:200]'  # 只看前200字
```

## 5. 完整的 Shell 脚本示例

```bash
#!/bin/bash
# bot_search 一键搜索脚本

QUERY=${1:-"信创产业 2025"}
MAX=${2:-3}
API="http://localhost:8300"

echo "🔍 搜索: $QUERY"
echo ""

# 发起搜索
RESP=$(curl -s -X POST "$API/search" \
  -H "Content-Type: application/json" \
  -d "{\"query\": \"$QUERY\", \"keyword\": \"$QUERY\", \"max_results\": $MAX}")

SESSION_ID=$(echo $RESP | jq -r '.session_id')
echo "📋 会话: $SESSION_ID"

# 轮询
while true; do
  POLL=$(curl -s "$API/poll/$SESSION_ID")
  STATUS=$(echo $POLL | jq -r '.status')
  echo "⏳ 状态: $STATUS"
  if [ "$STATUS" = "done" ]; then
    echo ""
    echo "✅ 完成！耗时: $(echo $POLL | jq -r '.elapsed')s"

    # 输出概览
    echo ""
    echo "📊 文章概览:"
    echo $POLL | jq -r '.articles | to_entries[] | "  \(.key): \(.value.title) (\(.value.segments | length) 个分组)"'

    echo ""
    echo "📝 分组要点:"
    echo $POLL | jq -r '.segments | to_entries[] | "  \(.key): \(.value.point)"'

    # 保存全量结果
    echo $POLL > bot_search_result.json
    echo ""
    echo "💾 结果已保存到 bot_search_result.json"
    break
  elif [ "$STATUS" = "error" ]; then
    echo "❌ 错误: $(echo $POLL | jq -r '.error')"
    break
  fi
  sleep 5
done
```

使用方式：

```bash
bash search_demo.sh "国产芯片 替代" 3
```

## 6. 查看结果概览（status）

不拿全量数据，只看概览：

```bash
curl -s http://localhost:8300/status/s_20250707_143000_...
```

返回：

```json
{
  "session_id": "s_20250707_143000_...",
  "status": "done",
  "query": "国产芯片 替代 2025",
  "keyword": "国产芯片",
  "created_at": "2025-07-07T14:30:00+00:00",
  "elapsed": 45.2,
  "article_count": 3,
  "error": null
}
```

## 7. 清理会话

```bash
curl -s -X POST http://localhost:8300/close/s_20250707_143000_...
```

## 典型流程时序图

```
客户端                      API 服务                   Ollama
  │                          │                          │
  │── POST /search ─────────→│                          │
  │←── {session_id, processing}                         │
  │                          │── 后台线程 ──────────────→│
  │                          │    搜索+提取+分块          │
  │                          │    ←── stage1 分组 ──────│
  │                          │    合并+补充遗漏           │
  │                          │                          │
  │── GET /poll ────────────→│                          │
  │←── {status: processing}  │                          │
  │                          │                          │
  │── GET /poll ────────────→│                          │
  │←── {status: done, data}  │                          │
  │                          │                          │
  │── POST /segment ────────→│                          │
  │←── {原文内容}            │                          │
  │                          │                          │
  │── POST /close ──────────→│                          │
  │←── {status: closed}      │                          │
```
