# 日终收盘分析报告 Skill

## 触发条件

用户要求生成「日终收盘分析报告」时使用。日终=晚间完整复盘+次日计划;数据优势:当日龙虎榜实锤、当日涨停/炸板、全日资金流——必须充分利用。

## 上下文对应(先读,每个数据块喂给哪个章节)

| 上下文块 | 用于 |
|---|---|
| 数据块(`### {name}({ts_code})数据` 下各节) | 见下表 |
| 【今日全市场情绪】 | 开头·全市场环境一行 |
| 【今日收盘 {name}情况】 | 盘面(形态/量能/日内位置) |
| 【个股资金流】(Tushare+雪球) | 资金面·主力(多日累计/逐日/时段,两口径是否一致) |
| 【龙虎榜】 | 资金面·游资(席位构成:机构专用多=机构行情,营业部多=游资行情) |
| 【大宗交易】 | 资金面·游资/机构(席位定性、折溢价;无记录=常态不写风险) |
| 【融资融券多日分析】 | 融资融券面(方向/拥挤度/成本区/20日量价关系) |
| 【机构持仓】(同花顺F10) | 机构面(成本估算/持仓轨迹/主动 vs 被动/新进增持减持) |
| 【机构调研】(stk_surv) | 机构面·调研要点(频次同比→关注度;名单→谁在关注;纪要→管理层核心信息) |
| 【券商评级与盈利预测】 | 机构面·评级要点(素材=数据块"## 【券商评级与盈利预测】"节: 📊统计区为6个月整体态度, 逐条区为近90天研报; 无数据写"券商评级数据未获取,无法判断") |
| 【北向持股】 | 机构面(外资维度佐证) |
| 【十大流通股东】 | 机构面(大股东增减持佐证) |
| 【股东户数】 | 资金面·散户(注明数据日期;>90 天仅作趋势背景) |
| 【风险日历】 | 总结·主要风险(解禁/质押/财报披露日期) |
| 【涨停/炸板】 | 盘面(异常)+ 资金面·游资(连板=游资行为) |
| 【板块地位】 | 盘面(强弱对比:跑赢/跑输所属板块)+ 涨跌归因 |
| 【技术面与成本地图】 | 盘面(均线/BOLL 位置)+ 总结·价格处境 |
| 【筹码成本分布】(cyq) | 总结·成本地图四锚点(筹码加权成本)+ 各面成本交叉验证 |
| 【业绩趋势】 | 涨跌归因(基本面)+ 机构面(回流条件) |
| 消息块(`### {name}...消息` 的【盘中异动监测】) | 盘面(异常)+ 涨跌归因(快讯匹配不到个股=正常,不得编造) |
| 资讯列表(`### {name}...相关新闻资讯列表`) | 资讯面(需正文时用 fetch_article_body) |

## 输出骨架(必须逐字复制,只替换占位符内容)

```markdown
# {股票名}({代码})日终收盘分析 — {YYYY-MM-DD}

{一段话总定性:今日行情性质一句话(涨跌/量能/形态)→ 异常与强信号(如有)→ 影响决策的因素(如有),自然融入}

全市场:{热度(低/中/高)} | {成交额,与昨日对比} | 上涨{家数}/下跌{家数} | 涨停{家数}家、跌停{家数}家 | {领涨或领跌板块}

> 数据口径说明:{仅当数据含盘中快照/T-1 滞后/基准日期不一致时输出,一行说清哪些数据滞后}

### 📉 盘面:{判断句副题}

{一句话形态定性。}

- **{要点名}**:{结论句。**关键数字加粗**。数字后一句解读。}
- **{要点名}**:{形态/量能/日内位置/强弱对比,共 3-5 点}

### 💰 资金面:{判断句副题}

- **主力**:{3/5/10 日累计方向 → 逐日结构 → 今日时段与单日大单 → 两口径是否一致 → 结论:能否确认持续进场}
- **游资**:{龙虎榜上榜原因、席位构成;未上榜写"缺少龙虎榜数据,无法从席位层面确认游资动向";大宗交易席位佐证}
- **散户**:{小单方向 + 股东户数(注明数据日期)+ 与主力是否对手盘}
- **综合**:{谁在买、谁在卖,一句话资金结构}

### 🏢 机构面:{判断句副题}

- **成本与盈亏**:{机构估算成本 X 元,现价偏离 ±X%,账面盈利/亏损}
- **持仓轨迹**:{各期占比+对应股价 → "被套在里面"还是"已在下跌中卖出大半" → 主动基金 vs 被动 ETF → 边际变化}
- **机构调研**:{近 3 月/近 365 天频次与同比 → 名单构成(公募/券商/外资)→ 纪要核心信息,与基本面交叉验证}
- **券商评级**:{目标: 机构态度(评级/目标价/盈利预期)与现价、基本面是否背离。素材: 数据块"## 【券商评级与盈利预测】"节。步骤: 1)见"❌ 券商评级: 库中无该股研报数据"→写"券商评级数据未获取,无法判断";2)先看📊统计区(评级分布/目标价区间)定整体态度, 再逐条读近90天研报(按时间近到远): 评级+目标价(≥X元)对比现价算空间+最新季净利润/EPS预测, [行业]报告仅作行业背景;3)与【业绩趋势】对照, 预测与趋势背离要指出}
- **结论**:{成本区是支撑还是压力 + 机构重新进场需要什么条件}

### ⚖️ 融资融券面:{判断句副题}

- **方向**:{5/10/20 日余额变化+净买入 → 杠杆在加仓还是离场;20 日量价关系(余额降价升=杠杆未参与上涨)}
- **拥挤度**:{占流通市值 % + 近一年分位;>80% 且价格下跌=被迫卖出风险预警}
- **成本与循环风险**:{成本区 vs 现价(亏损/盈利幅度)→ "下跌→被迫卖出→再下跌"循环风险;融券规模小可略}

### 🔍 涨跌归因:{判断句副题}

- **主因**:{归因因素一句话 + 证据(板块带动?公司自身?资金?情绪?)}
- **次因**:{第二顺位因素 + 证据}
- **消息面**:{有/无新增消息,对今日涨跌的实际贡献}
- **定性**:{一句话:今日涨跌是 XX 驱动,不是 XX}

### 📰 资讯面:{判断句副题}

- **直接影响个股**:{每条:消息要点 + (状态:已兑现/待反应/在发酵;利多/利空/中性)+ 一句理由}
- **影响板块**:{每条同上}
- **背景性**:{每条同上}
- **小结**:{消息面对今日行情的实际贡献 + 下一步要盯的事件}。今日无个股新增消息时,仍展示消息面内容,并写"今日涨跌与消息无关"

### 🎯 总结与策略:{判断句副题}

- **行情定性**:{一句话}
- **核心矛盾**:{多方与空方的力量对垒,各一句话}
- **价格处境**:{成本地图四锚点 + 支撑/压力带}
  - **机构持仓成本**:{X 元 | 现价偏离 ±X%}
  - **融资盘成本**:{X 元(区)| 现价偏离 ±X%}
  - **筹码加权成本**:{X 元 | 现价偏离 ±X%}
  - **MA20**:{X 元 | 现价偏离 ±X%}
  - {支撑带与压力带一句话}
- **主要风险**:{1-4 条,每条条件式}
- **观察点**(明日午间报告会逐条核对这些观察点):{3-5 条,每条:具体信号 + 数据来源 + 预计出现时间 + 条件式决策倾向}
```

## 要点写法示例

- **深V反转**:开盘暴跌后 5 分钟内拉升超 2%,盘中最高 **168.98 元**,多空在 150-169 元区间大规模换手。
- **主力净流入不持续**:3 日累计 **+2.68 亿**,但 0804 单日占 **2.52 亿**,随后逐日递减,只能算迹象,不能确认主力进场。

## 写作铁律

1. **骨架必须逐字复制**:7 章顺序、标题层级(###)、emoji、判断句副题、每章要点框架,不得增删章节、不得改层级
2. 章节副题是判断句,不是数据类型名("主力出逃、散户逆势抄底",不写"资金面分析")
3. 每个要点:结论句或主体名加粗领起;结论句在前,数据在后;关键数字加粗;每个数字后一句解读
4. 分析占全篇 ≥80%,每要点只引 3-5 个关键数据;宁可少一个数据,不可少一句判断
5. 全篇禁止表格(包括盘面与成本地图,一律要点行);禁止黑话、符号指代、占位符
6. 阶段判断(吸筹/洗盘/拉升/出货)必须附证伪条件("出现什么数据此判断失效")
7. 观察点必须条件式(如果 X 则 Y),含数据来源与预计出现时间;结尾固定句"明日午间报告会逐条核对这些观察点"
