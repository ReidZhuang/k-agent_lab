# 午间收盘分析报告 Skill

## 触发条件

用户要求生成「午间收盘分析报告」时使用。午间=盘中决策工具,只在两类日子看:行情特别好的追涨日、个股买卖急迫的关键日。决策窗口=下午 2 小时,开头 30 秒判断"有事没事",有事再读证据层。

## 午间独有规则

- **当日龙虎榜未出**(T 日 17:30 后才有):游资小节必须写"当日龙虎榜未出,当日游资动向待盘后确认",不得用 T-1 数据冒充
- **今日盘中资金流不分角色**:主力小节中无法确认的部分要坦白
- **异常扫描**(盘面章内):盘中异动/涨停被打开/快速跳水/突发消息/T-1 龙虎榜大卖/融资拥挤异常/破位关键均线——全部无异常时写一行"未发现异常";有异常时每个:是什么+意味着什么+要不要行动
- **前一日日终报告观察点核对**:午间报告必须逐条核对前一日日终报告的观察点(命中/未命中/待确认),这决定今日行动是否有据

## 上下文对应(先读,每个数据块喂给哪个章节)

| 上下文块 | 用于 |
|---|---|
| 数据块(`### {name}({ts_code})数据` 下各节) | 见下表 |
| 【今日全市场情绪】 | 开头·全市场环境一行 |
| 【今日11:30收盘 {name}情况】(快照) | 盘面(半日形态/量能/日内位置) |
| 【个股资金流】(Tushare, T-1) | 资金面·主力(多日方向)+ 今日盘中大单(不分角色) |
| 【龙虎榜】(T-1) | 资金面·游资(写明"当日龙虎榜未出,待盘后确认") |
| 【大宗交易】 | 资金面·游资/机构(席位定性;无记录=常态不写风险) |
| 【融资融券多日分析】 | 融资融券面(方向/拥挤度/成本区) |
| 【机构持仓】(同花顺F10) | 机构面(成本估算/持仓轨迹/主动 vs 被动) |
| 【机构调研】(stk_surv) | 机构面·调研要点(频次同比→关注度;名单→谁在关注;纪要→管理层核心信息) |
| 【券商评级与盈利预测】 | 机构面·评级要点(素材=数据块"## 【券商评级与盈利预测】"节, 逐条研报: 评级/目标价/盈利预测; 无数据写"券商评级数据未获取,无法判断") |
| 【股东户数】 | 资金面·散户(注明数据日期;>90 天仅作趋势背景) |
| 【风险日历】 | 午后策略(风险/解禁/财报日期) |
| 【板块地位】 | 盘面(强弱对比)+ 涨跌归因 |
| 【技术面与成本地图】 | 盘面(均线位置)+ 午后策略(支撑/压力) |
| 【业绩趋势】 | 涨跌归因(基本面) |
| 【公告补充】(T-1 至今日上午) | 涨跌归因·消息面 |
| 【行业关键词】 | 涨跌归因(板块催化) |
| 消息块(`### {name}...消息` 的快讯/异动) | 盘面·异常扫描 + 涨跌归因(匹配不到个股=正常,不得编造) |
| 资讯列表(`### {name}...相关新闻资讯列表`) | 涨跌归因·消息面(需正文时用 fetch_article_body) |

## 输出骨架(必须逐字复制,只替换占位符内容)

```markdown
# {股票名}({代码})午间收盘分析 — {YYYY-MM-DD}

{一段话总定性:上午行情性质一句话 → 上午最值得注意的 2-3 点 → 影响下午决策的因素,自然融入}

全市场:{热度(低/中/高)} | {成交额,与昨日对比} | 上涨{家数}/下跌{家数} | 涨停{家数}家、跌停{家数}家 | {领涨或领跌板块}

> 数据口径说明:{仅当数据含盘中快照/T-1 滞后/基准日期不一致时输出,一行说清哪些数据滞后}

### 📉 盘面:{判断句副题}

{一句话形态定性。}

- **形态**:{上午走势一句话 + 关键节点}
- **量能**:{半日成交/换手 vs 昨日全天,放量/缩量含义}
- **位置**:{现价在日内区间/关键均线的位置}
- **异常扫描**:{有:每个=是什么+意味着什么+要不要行动;全部无异常写一行"未发现异常"}

### 💰 资金面:{判断句副题}

- **主力**:{T-1 多日方向(3/5/10 日)→ 今日盘中大单;今日盘中资金流不分角色,无法确认的部分要坦白}
- **游资**:{T-1 龙虎榜定性;写"当日龙虎榜未出,当日游资动向待盘后确认";大宗交易席位佐证}
- **散户**:{T-1 小单方向 + 股东户数(注明数据日期)+ 与主力是否对手盘}
- **综合**:{谁在买、谁在卖,一句话资金结构}

### 🏢 机构面:{判断句副题}

- **成本与盈亏**:{机构估算成本 X 元,现价偏离 ±X%,账面盈利/亏损}
- **持仓轨迹**:{各期占比+对应股价 → "被套在里面"还是"已在下跌中卖出大半" → 主动基金 vs 被动 ETF → 边际变化}
- **机构调研**:{近 3 月/近 365 天频次与同比 → 名单构成(公募/券商/外资)→ 纪要核心信息,与基本面交叉验证}
- **券商评级**:{目标: 机构态度(评级/目标价/盈利预期)与现价、基本面是否背离。素材: 数据块"## 【券商评级与盈利预测】"节。步骤: 1)见"❌ 券商评级: 库中无该股研报数据"→写"券商评级数据未获取,无法判断";2)逐条读研报(数据已按时间近到远排列): 评级+目标价(≥X元/区间)对比现价算空间+最新季净利润/EPS预测, [行业]报告仅作行业背景;3)与【业绩趋势】对照, 预测与趋势背离要指出}
- **结论**:{成本区是支撑还是压力 + 机构重新进场需要什么条件}

### ⚖️ 融资融券面:{判断句副题}

- **方向**:{5/10/20 日余额变化+净买入 → 杠杆在加仓还是离场;20 日量价关系}
- **拥挤度**:{占流通市值 % + 近一年分位;>80% 且价格下跌=被迫卖出风险预警}
- **成本与循环风险**:{成本区 vs 现价(亏损/盈利幅度)→ "下跌→被迫卖出→再下跌"循环风险;融券规模小可略}

### 🔍 涨跌归因:{判断句副题}

- **主因**:{归因因素一句话 + 证据(板块带动?公司自身?资金?情绪?)}
- **次因**:{第二顺位因素 + 证据}
- **消息面**:{今日上午新增公告/消息(可引【公告补充】与资讯),对上午涨跌的实际贡献;无新增消息写"今日无新增公司消息"}
- **定性**:{一句话:上午涨跌是 XX 驱动,不是 XX}

### 🎯 午后策略:{判断句副题}

- **昨日观察点核对**:{逐条核对前一日日终报告的观察点:命中/未命中/待确认,各一句}
- **午后观察点**:{2-3 条,条件式,含数据来源与预计出现时间}
- **条件式建议**:{1-2 句,非指令:"若午后 X 则持有逻辑成立;若 Y 失守则今日不宜加仓"}
```

## 写作铁律

1. **骨架必须逐字复制**:6 章顺序、标题层级(###)、emoji、判断句副题、每章要点框架,不得增删章节、不得改层级
2. 章节副题是判断句,不是数据类型名
3. 每个要点:结论句或主体名加粗领起;结论句在前,数据在后;关键数字加粗;每个数字后一句解读
4. 分析占全篇 ≥80%,每要点只引 3-5 个关键数据;宁可少一个数据,不可少一句判断
5. 全篇禁止表格(一律要点行);禁止黑话、符号指代、占位符
6. 阶段判断必须附证伪条件;观察点必须条件式(如果 X 则 Y)
7. 前一日日终报告存在时,午后策略章必须逐条核对它的观察点,不得遗漏
