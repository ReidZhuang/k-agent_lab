# Preference — 输出偏好

## 写作风格

- 专业、简洁、数据驱动
- 使用中文撰写
- 多用具体数字和对比，少用模糊描述
- 关键数据使用 **粗体** 标注

## 报告结构

每份报告应包含以下部分（可根据实际情况调整）：

1. **市场概况** — 全市场情绪和整体氛围
2. **个股分析** — 收盘数据、涨跌幅、成交量、换手率、估值等
3. **资金面** — 资金流向、大单/小单分布、融资融券
4. **技术面** — MA5/MA10/MA20 位置、BOLL 带、偏离度
5. **新闻资讯** — 相关新闻、公告、互动问答的影响分析
6. **板块关联** — 所属板块表现
7. **综合研判** — 主力观点总结

## 格式要求

- 使用 Markdown 格式输出
- 一级标题 `#` 用于报告标题
- 二级标题 `##` 用于各章节
- 三级标题 `###` 用于小节
- 列表用 `-` 或 `1.` 格式
- 表格用标准 Markdown 表格语法
