# fetch_article_body

## 描述

获取指定文章的正文内容。当 `articles` 列表中某篇文章的 `body_avail` 为 "有",且仅凭标题和摘要无法判断其对分析的价值时,调用此工具获取全文。

## 适用范围

本工具仅适用于 **"相关新闻资讯列表"** 部分中列出的文章。只有该部分的文章可以通过 article_id 获取正文。

## 输入参数(JSON Schema)

严格遵循工具定义的 schema,`articles` 参数必须是"来源引擎 → 文章 ID 列表"的映射对象。

## 输出格式(硬性要求)

不同来源引擎的文章 ID 存在重复(如 `thsnews` 与 `sinafin` 都有 `a_01`),因此调用工具时必须**按来源引擎分组输出**,禁止在 ID 上添加引擎前缀:

```json
{
  "articles": {
    "thsnews": ["a_01", "a_02", "a_05"],
    "sinafin": ["a_01", "a_03"]
  }
}
```

规则:
- **key(引擎名)**:必须原样使用『相关新闻资讯列表』中 `**来源: xxx**` 标注的引擎名(如 `thsnews`/`sinafin`/`thsfin`/`baidufin`/`juchao`/`qnainfo`)
- **value(文章 ID)**:必须原样使用该引擎下 `ID:` 字段的值(如 `a_01`),**禁止添加引擎前缀**(如 `thsnews_a_01` 是错误的)、禁止拼接、禁止改名
- 同一引擎的多篇文章合并为一个列表项;只包含 `body_avail='有'` 的文章

## 使用原则

- 优先调用标题涉及"业绩预告/快报"、"重大合同"、"回购/增持/减持"、"监管/处罚"等 P0 级事件的正文
- 标题相似度较高(同一事件多源报道),只调用信息量最丰富的一篇
- 如果摘要已包含足够信息(如业绩快报的具体数字),则**不需要**调用正文
- 单次轮次尽量批量调取,避免多次往返
