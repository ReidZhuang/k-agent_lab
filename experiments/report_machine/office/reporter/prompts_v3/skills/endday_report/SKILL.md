# 日终收盘分析报告 Skill

## 触发条件

用户要求生成「日终收盘分析报告」时使用。日终=晚间完整复盘+次日计划;数据优势:当日龙虎榜实锤、当日涨停/炸板、全日资金流——必须充分利用。

## 上下文对应(先读)

| 上下文块 | 内容 | 用于 |
|---|---|---|
| 数据块(`### {name}...数据`) | 取数脚本各节:行情/融资/龙虎榜/资金流/机构/户数/风险/涨停/板块/技术/业绩/大宗 | 盘面、资金面、机构面、融资融券面、归因 |
| 消息块(`### {name}...消息`) | 快讯/盘中异动 | 盘面、异常、归因(快讯匹配不到个股=正常,不得编造) |
| 资讯列表(`### {name}...相关新闻资讯列表`) | 5 引擎文章(标题+摘要) | 资讯面(需正文时用 fetch_article_body) |

## 固定结构(严格按序,7 章)

# {{stock_name}}({{ts_code}})日终收盘分析 — {{YYYY-MM-DD}}

**开头**:一段话总定性(今日行情性质)+ 三个问题自然段:今天有没有异常?有没有强烈信号?有没有影响决策的因素?+ 全市场环境一行(热度/上涨占比/涨跌停/大盘/领涨领跌)

### 一、盘面

[判断句标题。形态(分时三段式:冲高-回落-企稳等)+ 量能(放量/缩量,与昨日对比)+ 收在日内位置 + 跑赢/跑输板块多少。只述量价事实,不下买卖结论]

### 二、资金面

- **主力**:多日方向(3/5/10 日累计)→ 强度 → 时段结构(早/午/尾盘)→ 多口径是否一致 → 结论:能否确认持续进场
- **游资**:龙虎榜上榜原因定性、席位构成(机构专用多=机构行情,营业部多=游资行情)、买一集中度;未上榜写"今日未上龙虎榜,无法从席位层面确认游资动向"
- **散户**:小单方向 + 股东户数(注明数据日期)+ 与主力是否对手盘
- **综合**:谁在买、谁在卖,一句话资金结构

### 三、机构面(机构成本三段式,必做深)

1. **成本**:机构平均买入成本(用脚本加权估算;有分价位成交分布时从成交密集价位推断)
2. **状态**:现价距成本多少%(账面盈利/亏损)
3. **行为与含义**:结合持仓轨迹(各期占比+对应股价)→ 机构是"被套在里面"还是"已在下跌中卖出大半"→ 成本区还剩多少真实持仓 → 主动基金 vs 被动 ETF → 结论落在:成本区是支撑还是压力 → 调研/券商覆盖佐证 → 机构重新进场需要什么条件

### 四、融资融券面

方向(5/10/20 日余额+净买入)→ 拥挤度(占流通市值比例+近一年分位,>80% 且价格下跌=被迫卖出风险预警)→ 成本区 vs 现价(亏损幅度→"下跌→被迫卖出→再下跌"循环风险)→ 融券(规模小可略)

### 五、涨跌归因

板块带动?公司自身(公告/业绩)?资金?情绪?→ 主次排序 → 一句话定性

### 六、资讯面(四步法)

1. 筛选三类:直接影响这只股票的 / 影响整个板块的 / 背景性的
2. 每条判定状态:已兑现(价格已反应)/ 待反应(还没反应)/ 在发酵
3. 每条一句影响判断(利多/利空/中性)
4. 小结:消息面对今日行情的实际贡献 + 下一步要盯的事件

[今日无新增个股消息时,仍要展示消息面内容,并说明"今日上涨与消息无关"]

### 七、总结与策略

行情定性 + 核心矛盾 + 价格处境(支撑/压力带;可用成本地图四锚点小表:机构成本/融资成本/MA20/BOLL 上轨,每锚标现价偏离)+ 主要风险 + 3-5 个观察点(每个含:具体信号+数据来源+预计出现时间+条件式决策倾向)

## 写作铁律

1. 章节标题是判断句,不是数据类型("机构成本:高位建仓,成本不菲")
2. 阶段判断(吸筹/洗盘/拉升/出货)必须附证伪条件("出现什么数据此判断失效")
3. 观察点必须条件式,结尾注明"明日午间报告会逐条核对这些观察点"
4. 禁止独立表格:仅盘面核心数据、成本地图四锚点可表
