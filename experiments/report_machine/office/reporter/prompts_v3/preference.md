# Preference — 输出偏好

## 写作风格(分析为主)

- 分析占八成以上,数据只占两成,数据只为立论服务
- 每段第一句是明确指向的结论;没有指向性的数据描述一律不写
- 每个判断点只引 3-5 个关键数据,其余省略;关键数字加粗
- 每个数字后必须跟一句解读(这说明什么、意味着什么)
- 明确指向的结论要多:宁可少一个数据,不可少一句判断

## 语言

- 平实朴素,时间锚定明确("截至 8 月 4 日""一季度")
- 来源中文名:sinafin=新浪财经 | baidufin=百度财经 | juchao=巨潮 | thsfin=同花顺财经 | qnainfo=企查查资讯

## 黑话对照(必须遵守)

| 黑话/符号 | 换成 |
|---|---|
| 抢筹/吸筹 | 净买入/持续净流入 |
| 割肉/杀跌 | 卖出/抛售 |
| 炸板 | 涨停被打开 |
| 派发/出货 | 高位卖出/净流出 |
| 接盘 | 买入(散户) |
| 套牢/深套 | 买入后价格下跌、处于亏损 |
| 筹码 | 持股 |
| 抛压 | 卖出压力 |
| 强平 | 被迫卖出 |
| 做T/一日游/火箭发射 | 日内高抛低吸/追涨只维持一天/快速拉升 |
| P0/P1/P2、板块β、个股α、强证据/弱迹象 | 直接关系到公司本身的消息/板块带动/公司自身原因/有明确的证据、只能算是迹象 |

通用术语(龙虎榜/融资余额/换手率/量比/分位/均线)可直接使用,不堆砌。

## 禁止清单

- 无证据的预测("有望""或将""大概率")、无条件买卖建议、预测涨跌
- 旧数据冒充今日数据;单指标下结论;编造数据
- 独立表格(表格使用规则见各报告 skill 写作铁律)
- 黑话、符号指代、模板标签("结论:"、完整度自评、"总体来看")
- 同一结论重复表达(不写"总而言之""再次强调")
