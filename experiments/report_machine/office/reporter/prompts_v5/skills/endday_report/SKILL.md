# 日终收盘分析报告 Skill

## 触发条件

用户要求生成「日终收盘分析报告」时使用。日终=晚间完整复盘+次日计划;数据优势:当日龙虎榜实锤、当日涨停/炸板、全日资金流——必须充分利用。

## 大宗交易解读规则(实锤级证据)

- 席位定性:含"机构专用"归机构/主力;营业部实名归游资,与龙虎榜交叉(同席位多次出现=同一资金连续动作)
- 折溢价:大幅折价(>5%)=卖方急于变现(偏空);平价/溢价=买方意愿强(偏多)
- 规模:单笔 <500 万=噪音;连续多日或大额才升级为证据
- 事件关联:减持/解禁公告同期的大宗=减持通道实锤,写入风险
- 成本锚:大宗成交价≈接盘方买入成本,与机构成本/融资成本交叉验证
- 禁止:仅凭"有大宗"断言主力进出;无大宗=常态,不写风险

## 日终独有规则

1. **骨架必须逐字照抄**:7 章顺序、标题层级(###)、emoji、判断句副题、分析点编号,不得增删章节、不得改层级
2. **章节副题是判断句**,是本章结论(如"主力出逃、散户逆势抄底"),不是数据类型名(不写"资金面分析")
3. **结论项置首**:每面第 1 条是结论项,统一写 `**总结**` 无编号小标题,先结论后内容,结论句整体加粗,其下数据子要点不加粗;总结后跟 1 句前瞻指引,不加粗
4. **游资分析分支**:当日龙虎榜有记录→按席位构成分析实锤(机构专用多=机构行情,营业部多=游资行情);无记录(多数情况,常态)→先基于涨停/连板/大宗交易/换手率等特征给出游资参与度结论,再补一句"今日未上龙虎榜,无法从席位层面实锤"。禁止把"未上榜"写成主要内容;无龙虎榜记录时小节输出顺序固定:先游资行为总结(基于涨停/连板/大宗交易/换手率等特征),再一句后市游资前瞻(参与是否延续、什么信号确认或退潮),最后一句才点明"今日未上龙虎榜,无法从席位层面实锤",不得以"未上龙虎榜/无法实锤"开头
5. **资金阶段判断**(建仓/持有/出逃)必须附证伪条件:写出什么数据出现时该判断失效
6. **风险与观察点归属**:风险/观察点是每面紧跟总结的无编号小标题(顶格置前),不得出现在编号分析点中,不得在总结与策略章重复罗列;总结与策略章只保留行情定性/核心矛盾/价格处境三项
7. **风险条目格式**(见 Preference 规则 6):每条 = 风险是什么 + 触发条件 + 若触发的大致市场反应(一句,点到为止,不预测涨跌幅度与概率)
8. **观察点必须条件式**(如果 X 则 Y),含数据来源与预计出现时间
9. 输出前按 Agent 检查清单 + Preference 全部规则自查
