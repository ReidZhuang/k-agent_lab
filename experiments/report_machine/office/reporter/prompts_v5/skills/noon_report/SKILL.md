# 午间收盘分析报告 Skill

## 触发条件

用户要求生成「午间收盘分析报告」时使用。午间=盘中决策工具,只在两类日子看:行情特别好的追涨日、个股买卖急迫的关键日。决策窗口=下午 2 小时,开头 30 秒判断"有事没事",有事再读证据层。

## 数据块 → 章节映射(数据块标题按此精确匹配)

| 数据块标题 | 喂给 |
|---|---|
| ## 全市场情况(含【今日全市场情绪】) | 开头·全市场一行 |
| 📌 股票涉及行业关键词 | 涨跌归因·板块催化 |
| 【今日11:30收盘 {name} ({ts_code})情况】 | 盘面 |
| 【融资融券多日分析】 | 融资融券面 |
| 【龙虎榜】 | 资金面·游资(写明"当日龙虎榜未出,待盘后确认") |
| 【个股资金流】 | 资金面·主力(多日方向)+ 今日盘中大单(不分角色) |
| 【机构持仓】 | 机构面·成本与持仓轨迹 |
| 【机构调研】 | 机构面·调研:频次同比→关注度;名单→谁在关注(午间无纪要全文) |

| 【技术面与成本地图】 | 盘面·位置 + 午后策略·支撑压力 |

| 【公告补充】 | 涨跌归因·消息面 |

## 大宗交易解读规则(实锤级证据)

- 席位定性:含"机构专用"归机构/主力;营业部实名归游资,与龙虎榜交叉(同席位多次出现=同一资金连续动作)
- 折溢价:大幅折价(>5%)=卖方急于变现(偏空);平价/溢价=买方意愿强(偏多)
- 规模:单笔 <500 万=噪音;连续多日或大额才升级为证据
- 事件关联:减持/解禁公告同期的大宗=减持通道实锤,写入风险
- 成本锚:大宗成交价≈接盘方买入成本,与机构成本/融资成本交叉验证
- 禁止:仅凭"有大宗"断言主力进出;无大宗=常态,不写风险

## 输出骨架(硬格式:章节、标题、层级、占位符内容要求必须照抄;分析点数量与子要点自由增减)

分析点格式见 Preference 结构规则 3:`- **{分析点名}**:{结论句}。` 结论句回答括号内的问题。

```markdown
# {股票名}({代码})午间收盘分析 — {YYYY-MM-DD}

{1-2 句总定性:上午行情的核心结论,纯文字,不列数据}
- {关键数据 1}
- {关键数据 2}
- {关键数据 3}    ← 最多 3 条

全市场:{热度} | {成交额,与昨日对比} | 上涨{家数}/下跌{家数} | 涨停{家数}家、跌停{家数}家 | {领涨或领跌板块}

> 数据口径说明:{仅当数据含盘中快照/滞后/基准日期不一致时输出一行;无则省略}

### 📉 盘面:{一句话结论副题}

- **形态**:{结论句:上午走势什么性质}
- **量能**:{结论句:半日量能意味着什么}
- **位置**:{结论句:现价在日内区间/均价线的什么处境}
- **异常扫描**:{结论句:有异常时逐条(是什么+意味着什么+要不要行动);全部无异常写一行"未发现异常"}

### 💰 资金面:{一句话结论副题}

- **主力**:{结论句:今日盘中主力是什么状态;资金流不分角色,无法确认的部分要坦白}
- **游资**:{结论句:当日游资动向;写"当日龙虎榜未出,当日游资动向待盘后确认",不得用上一交易日数据冒充}
- **散户**:{结论句:与主力是否对手盘}
- **综合**:{结论句:谁在买、谁在卖,资金结构一句话}

### 🏢 机构面:{一句话结论副题}

- **成本与盈亏**:{结论句:成本区对现价是支撑还是压力}
- **持仓轨迹**:{结论句:机构在被套、止盈还是正在离场}
- **机构调研**:{结论句:关注度变化与谁在关注}
- **券商评级**:{结论句:机构态度与现价、基本面是否背离}
- **结论**:{结论句:机构重新进场需要什么条件}

### ⚖️ 融资融券面:{一句话结论副题}

- **方向**:{结论句:杠杆在加仓还是离场}
- **拥挤度**:{结论句:是否存在拥挤踩踏风险}
- **成本与循环风险**:{结论句:是否存在下跌-被迫卖出-再下跌的循环风险}

### 🔍 涨跌归因:{一句话结论副题}

- **主因**:{结论句:上午涨跌第一驱动是什么}
- **次因**:{结论句:第二顺位因素}
- **消息面**:{结论句:今日上午新增消息对涨跌的实际贡献;无新增消息写"今日无新增公司消息"}
- **定性**:{结论句:上午涨跌是 XX 驱动,不是 XX}

### 🎯 午后策略:{一句话结论副题}

- **昨日观察点核对**:{结论句:逐条核对前一日日终报告的观察点:命中/未命中/待确认,各一句;前一日报告不存在则写明无法核对}
- **午后观察点**:{2-3 条,每条:具体信号 + 数据来源 + 预计出现时间}
- **条件式建议**:{1-2 句:若午后 X 则持有逻辑成立;若 Y 失守则今日不宜加仓}
```

## 午间独有规则

1. **骨架必须逐字照抄**:6 章顺序、标题层级(###)、emoji、判断句副题、分析点名,不得增删章节、不得改层级
2. **章节副题是判断句**,是本章结论(如"主力出逃、散户逆势抄底"),不是数据类型名(不写"资金面分析")
3. **当日龙虎榜未出**(当日盘后 17:30 才发布):游资小节必须写"当日龙虎榜未出,当日游资动向待盘后确认",不得用上一交易日数据冒充
4. **今日盘中资金流不分角色**:主力小节中无法确认的部分要坦白
5. **观察点必须条件式**(如果 X 则 Y),含数据来源与预计出现时间
6. 输出前按 Agent 检查清单 + Preference 全部规则自查
