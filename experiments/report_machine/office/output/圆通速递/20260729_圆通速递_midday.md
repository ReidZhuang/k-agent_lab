## 新闻资讯

### 重点新闻解读

**① 快递业量质齐升，行业景气度向好**（ID: a_02）

河北省上半年数据显示：快递业务量累计完成 **62.9亿件**，同比增长 **9.9%**（高于全国平均增速4.9个百分点）；快递业务收入同比增长 **12.8%**，收入增速 **高于业务量增速近3个百分点**，说明行业 **"内卷式"竞争有所缓解**，价格战降温、利润率改善趋势明显。

此外，文中特别提及 **圆通在河北的布局**：无人配送车投入运营有效降低派送成本，且多家快递企业入驻县域快递物流中心实现降本增效。圆通作为行业龙头之一，在县乡村三级寄递网络布局和智能化应用方面持续受益。

**② 融资余额降至近一年低位**

融资余额占流通市值比例仅 **0.25%**，低于近一年10%分位水平，一方面说明杠杆资金参与度低、做空压力小，另一方面也暗示短期缺乏融资客的增量支撑。

## 综合研判

**多空因素汇总：**

| 利好因素 | 利空因素 |
|---------|---------|
| 快递行业量质齐升，价格战趋缓 | 融资余额降至低位，杠杆资金观望 |
| 动态PE仅10.81倍，估值偏低 | 短线股价受MA5（17.58元）压制 |
| MA20（17.20元）提供中期支撑 | 早盘资金净流出295万元 |
| 运输板块中表现突出，跑赢同行 | 量比0.86，交投活跃度一般 |
| 大单资金前一交易日现小幅净买入 | 内盘>外盘，卖压略占优 |

**主力观点**：今日圆通速递在行业景气度改善（快递业量质齐升+价格战缓和）的利好催化下，逆势跑赢运输板块及物流子板块，表现稳健。估值端 **10.81倍动态PE** 提供安全边际，技术面MA20支撑有效，但短期受MA5压制，量能尚未充分释放。融资余额处于近一年低位，显示杠杆资金信心不足。午后关注能否放量突破 **17.58元（MA5）** 压力位，若能有效站稳，短期反弹空间有望进一步打开；若持续缩量，则大概率在 **17.20~17.58元** 区间整理蓄势。
