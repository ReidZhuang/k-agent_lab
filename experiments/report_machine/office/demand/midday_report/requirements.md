## 〇、报告定位(最重要,先读)

**午间报告是决策触发型工具,不是日常报告。**

使用场景(用户实测反馈):投资者只在两种日子看午间报告——
1. **行情特别好的日子**:想追涨/加仓,怕踏空(进攻性决策)
2. **个股买卖急迫的关键日子**:要决定下午卖不卖/该不该买(防守或出手决策)

两种场景共同点:**决策窗口只有下午 2 小时**。因此报告必须满足:
- **30 秒内判断"有事没事"**(三问直答置顶,见二)
- **有事再花几分钟读证据层**(完整分析,与日终同构)
- **分析为骨,数据为证**:输出的是分析判断,数据只作为证据引用;不得数据堆叠(上一版报告失败原因:全章数据表 + 一行解读,投资者认为"没用")

**与日终的关系**:日终报告是投资者需求的完整形态。午间 = 同一套分析逻辑(四步法)的盘中版,慢数据(融资融券/机构/风险日历/业绩/股东户数)在 11:30 与 18:30 拿到的完全一样、分析等级相同;只有盘中数据(行情/资金流/龙虎榜/涨停)降级或半日化。日终定"明日计划",午间做"当日触发校验"——午间报告应引用前一日日终的观察点做触发校验。

## 一、运行时间与数据时效矩阵

**运行时间**: 交易日 11:35(11:30 收盘后)。午间链路沿用现有调度(commander + crontab),取数脚本扩展、调用方不变。

**数据时效矩阵**(11:35 时点):

| 数据 | 实际日期 | 与日终差异 | 分析等级 |
|------|---------|-----------|---------|
| 行情快照(DB) | T 日半日(9:30-11:30) | 半日版 | 盘中降级 |
| 雪球 capital_flow/assort | T 日半日(逐分钟 9:30-11:30) | 半日版,可拆时段 | 盘中降级 |
| moneyflow 资金流 | **T-1**(T 日晚间才更新) | 日终可 T 日,午间只能 T-1 | 慢数据降级 |
| 龙虎榜 top_list/top_inst | **T-1**(T 日 17:30 才出) | 日终 T 日,午间 T-1 | **最大差异**:游资当日实锤缺失 |
| 融资融券 margin_detail + daily_basic | **T-1**(次日 8:30 更新) | 无差异 | **同等级**,250 日序列全量 |
| 机构持仓(同花顺 F10) | 最新报告期 | 无差异 | **同等级** |
| 机构调研/股东户数 | 最近公告日 | 无差异 | **同等级** |
| 解禁/质押/披露计划 | 未来 90 天 | 无差异 | **同等级** |
| 财务趋势 fina_indicator | 最近已披露报告期 | 无差异 | **同等级** |
| 涨停池/炸板(levistock) | T 日盘中实时 | 盘中实时版(封单动态) | 盘中降级 |
| 快讯(财联社) | T 日上午 | 实时 | 午间独有优势 |
| 公告探测 | T 日上午 | 半日 | 盘中降级 |
| 技术面 K线 | T 日半日(MA 按昨日收盘基准) | 半日 | 盘中降级 |
| 全市场情绪 | T 日 11:30 | 半日 | 盘中降级 |

**硬性纪律**:
- 任何数据块输出时附实际日期标签,严禁 LLM 混用日期
- 当日龙虎榜未出 → 游资章节必须写明"当日游资动向待盘后确认",不得编造

## 二、阅读路径(漏斗式,决定报告结构)

```
┌─ 三问直答(置顶,30 秒:有事没事)────────────┐
│ ① 有没有异常?                                 │
│ ② 有没有强烈信号(入手/出手)?                  │
│ ③ 有没有对决策影响较大的因素?                  │
└──────────────────────────────────────────────┘
        ↓ 有事才往下读
┌─ 证据层(完整分析,与日终同构,3-5 分钟)────────┐
│ 早盘发生了什么 / 异常扫描 / 谁在买卖 /          │
│ 杠杆资金 / 机构行为 / 阶段判断+归因 /            │
│ 驱动因素 / 关键位置 / 风险清单 / 资讯            │
└──────────────────────────────────────────────┘
        ↓
┌─ 午后观察点 + 顺着逻辑的小建议(收尾)──────────┐
└──────────────────────────────────────────────┘
```

**三问直答 vs 决策卡(边界,必须守住)**:
- ✅ 三问直答是**分析结论**:指出异常/信号/重大因素,陈述证据与强度,让投资者自己决策
- ❌ 决策卡是**行动指令**("买入条件:突破 X 可追")——已确认投资者不需要直接建议
- 允许的"建议"形式:全篇分析结束后,**顺着逻辑给 1-2 句倾向**(如"若午后延续放量,持有逻辑成立"这类条件式表述)

## 三、报告结构(分析为骨,数据为证)

> **写作铁律(全局)**:
> 1. 章节标题是**分析问题**,不是数据类型(如"主力上午在做什么?"而非"资金流向数据")
> 2. **禁止独立数据表格**:数据只能内嵌在分析句子里作为证据引用("尾盘 30 分钟净流入 2.4 亿,占半日成交 3.2%")。唯一例外:关键位置章的成本地图四锚点小表
> 3. **先结论后证据**:每段第一句是判断,数据在后支撑
> 4. **没有结论的数据不出现**:报告里每个数字必须服务于某个判断
> 5. 缺数据必须坦白:"缺少 XX 数据,无法判断 Y"

### 速览:三问直答(置顶,报告灵魂)

- **数据**: 下文各章结论
- **分析**: 三个问题的直接回答,每个回答附证据强度(实锤/强证据/弱迹象)
- **输出**: 固定三段式,每段 1-3 句

```
① 异常:有 —— 10:02 炸板 1 次 + 放量滞涨(量比 2.1),冲高回落形态(强证据)
         / 无 —— 未发现异常
② 强烈信号:入手 —— 放量突破 9.38 + 主力净流入 3 点共振(强证据)
          / 出手 —— 冲高回落 + 大单流出 + 炸板(实锤级)
          / 无 —— 今天不是动手日
③ 重大影响:有 —— 融资拥挤度 90% 分位 + 上午放量下跌,强平负反馈触发中(需重点盯防)
          / 无 —— 未见对决策有重大影响的因素
```

### 全市场环境(一行)

- **数据**: 市场热度/上涨占比/涨停家数/大盘指数(T 日 11:30)
- **分析**: 只呈现不展开;为个股解读提供情绪背景(行情好的日子:是否普涨可追)
- **输出**: 一行 blockquote

### 一、早盘发生了什么(盘面定调,分析段)

- **数据**: 半日行情(涨跌幅/开高低/现价/成交额/量比/内外盘/换手)、盘中形态
- **分析**:
  - 上午强势/弱势/震荡?量能配合还是背离?(结论先行)
  - 收在什么位置(日内高低区间的位置,结合 11:30 收盘位置占比)
- **输出**: 一段分析(2-4 句),数字内嵌;本节只陈述事实,不下判断

### 二、有没有异常(异常扫描,午间独有核心)

- **数据**: 盘中异动(急拉/急跌/大单异动/火箭发射)、涨停炸板(封单/开板)、快讯突发、T-1 龙虎榜大卖、融资拥挤度异常、破位关键均线
- **分析**: 逐项判断"无异常/有异常";有异常才展开——异常是什么、意味着什么、需不需要行动
- **输出**: 逐项清单(每项一行:状态 + 一句解释),全部无异常则一行"未发现异常"

### 三、谁在买卖(分角色分析)

#### 3.1 主力上午在做什么?
- **数据**: 雪球半日分钟流(时段拆分:9:30-10:00 / 10:00-11:00 / 11:00-11:30)+ capital_assort 半日 + T-1 moneyflow 角色结构(小/中/大/超大单)+ 融资余额(T-1)
- **分析**: 方向/强度(净额÷半日成交额)/时段结构(早盘拉升 vs 尾段撤退);结合 T-1 角色结构推断(注意"今日盘中总量不分角色"局限)
- **输出**: 一段分析(3-5 句)

#### 3.2 游资有什么动静?
- **数据**: T-1 龙虎榜(上榜原因/净买额/席位构成/买一集中度)+ 今日盘中涨停/炸板/异动(首封时间/开板)
- **分析**:
  - T-1 龙虎榜定性昨日资金性质(实锤,标注 T-1)
  - 今日盘中涨停基因:首封早=意愿强;开板次数=分歧度
  - **必须写明:"当日龙虎榜未出,当日游资动向待盘后确认"**
- **输出**: 一段分析(2-4 句)

#### 3.3 散户在接盘还是割肉?
- **数据**: T-1 小单净额 + 股东户数(最新期变化)
- **分析**: 散户接盘+价滞涨=出货确认;割肉+价企稳=筹码转移
- **输出**: 一句分析

### 四、杠杆资金怎么看(融资融券多日,与日终同等级)

- **数据**: margin_detail 250 日 + daily_basic(T-1,与日终完全相同)
- **分析**(与日终同规则,核心 3 + 派生 3):
  1. 杠杆方向:余额 5/10/20 日趋势 + 净买入方向
  2. 杠杆拥挤度:余额÷流通市值,近一年分位(>80% 高拥挤)
  3. 融资盘成本区 vs 现价(加权成本)
  4. 背离(有信号才写)/ 5. 买卖结构(有信号才写)/ 6. 融券(弱信号)
- **输出**: 一段分析 + 极简数字("拥挤度 90% 分位,成本区 8.6-8.9,现价在其上方 2.5%")

### 五、机构在干什么(机构行为,与日终同等级)

- **数据**: 同花顺 F10 4 端点(rate/tab/detail/rate_price)+ stk_surv 180 天
- **分析**: 机构成本估算(近 4 期加权)vs 现价;占比 8 期趋势(增仓/撤退);新进/减持结构(主动基金 vs 被动 ETF);调研频次(骤增=关注度上升,弱证据)
- **输出**: 一段分析(2-3 句)+ 成本锚一句话

### 六、资金阶段判断 + 上午涨跌归因(四步法核心)

- **数据**: 前三章 + 关键位置 + 资讯
- **分析**:
  - 阶段判断(吸筹/洗盘/拉升/出货)+ 证伪条件(必写)+ 证据强度
  - 四因子归因:板块 β(个股 vs 板块)/ 个股 α(业绩/公告/事件)/ 资金性质(谁主导)/ 情绪环境;标注主次
- **输出**: 阶段结论一行 + 归因 4 行 + 综合结论一行

### 七、驱动因素(近 5 日事件时间线)

- **数据**: 快讯(上午)+ 公告 + 资讯
- **分析**: P0/P1/P2 分层,标注事件-价格联动(上午快讯即时解读:对下午意味着什么)
- **输出**: 时间线列表(每行:日期 + 事件 + 层级 + 一句影响),只列 P0/P1

### 八、关键位置(技术面 + 成本地图)

- **数据**: 半日 K 线(MA5/10/20/BOLL,MA 按昨日收盘基准)+ 机构成本(章五)+ 融资盘成本(章四)
- **分析**: 现价离四个锚点(机构成本/融资成本/MA20/BOLL 上轨)哪个最近、支撑压力
- **输出**: **唯一允许的小表**——成本地图四锚点表(锚点/位置/现价偏离)+ 一句解读

### 九、风险清单(与日终同等级)

- **数据**: share_float(未来 90 天解禁)/ pledge_stat(质押)/ disclosure_date(披露计划)/ 融资拥挤度(章四)/ 炸板连板失败(章三)/ 高位获利盘(章八)
- **分析**: 逐项检查,存在则量化 + 一句解释,无则"未发现"
- **输出**: 风险项列表(每项一行),全部无则一行"未发现"

### 十、资讯/公告汇总

- **数据**: mail_tower 5 引擎(sinafin/baidufin/thsfin/juchao/qnainfo)+ 财联社快讯
- **分析**: P0/P1/P2 分层,**每条附一句影响判断**(不是罗列)
- **输出**: 分层列表,每条:来源 + 时间 + 一句影响

### 十一、午后观察点 + 顺着逻辑的小建议

- **数据**: 全文各章
- **分析**:
  - 午后观察点 3-5 个:每个 = 具体信号 + 数据来源 + 预计出现时间 + 条件式判断(如果 X 则意味着 Y)
  - 优先校验前一日日终报告的观察点是否被触发(触发校验)
- **输出**: 观察点列表 + 结尾 1-2 句条件式倾向(顺着逻辑的小建议,非指令)

### 完整度自评

- **输出**: 完整度(高/中/低)+ 信息缺失项 + 数据缺口对结论的影响(哪些结论降级为弱证据,如"当日龙虎榜未出,游资动向降级为迹象级")

## 四、报告范本(结构示例)

```markdown
# 天虹股份(002419.SZ)午间收盘分析 — 2026-07-31

### ① 异常:有 —— 10:02 炸板 1 次,放量滞涨(量比 2.1),冲高回落形态(强证据)
### ② 强烈信号:入手 —— 放量突破 9.38 且主力净流入(强证据);尚无出手信号
### ③ 重大影响:有 —— 融资拥挤度达近一年 90% 分位,上午放量下跌,强平负反馈风险触发中

> 市场热度 48(偏暖)| 上涨占比 62% | 涨停 58 / 跌停 42

## 一、早盘发生了什么
上午低开高走再回落,9:38 涨停后 10:02 炸板,现价 9.12(+1.79%),成交 8.7 亿已超昨日半日,量比 2.1。收于日内区间中上部,量能放大但上影线明显,冲高回落形态。

## 二、有没有异常
- 炸板:有 —— 10:02 炸板 1 次,封单从 1.8 亿撤至 0.3 亿,分歧加大(强证据)
- 放量滞涨:有 —— 炸板后价格横在 9.1 附近,量能未萎缩(强证据)
- 破位:无 / P0 快讯:无 / T-1 龙虎榜大卖:无

## 三、谁在买卖
**主力**:上午净流入 0.9 亿,其中 9:30-10:00 贡献 0.6 亿(拉升段),11:00 后转流出。叠加 T-1 大单净流入 1.2 亿,主力连续两日做多,但尾段有获利了结迹象。
**游资**:T-1 龙虎榜机构专用 2 席净买 1.2 亿 + 华鑫上海分公司净买 0.3 亿,买一集中度 55%(实锤,T-1)。今日盘中涨停 9:38 首封,炸板前封单 1.8 亿——有游资参与特征,但当日龙虎榜未出,当日游资动向待盘后确认。
**散户**:T-1 小单净流出 0.2 亿,股东户数环比 -2.1%,筹码集中中,未见接盘迹象。

## 四、杠杆资金怎么看
融资余额 5/10/20 日分别 +2.3%/+5.1%/+8.9%,拥挤度 90% 分位(近一年),融资盘成本区 8.6-8.9 元,现价在其上方 2.5%。杠杆持续加仓但已处高位,上午放量下跌若延续,存在强平负反馈风险——这是当前最需要盯防的信号。

## 五、机构在干什么
机构占比 8 期从 12.1% 升至 15.6%,机构成本估算 8.2 元,现价上方 11%。新进以主动型基金为主(中欧医疗 0.5 亿),非被动 ETF 调仓。中期支撑锚 8.2 元,距离尚远,机构无撤退迹象。

## 六、资金阶段判断与上午归因
**阶段**:拉升期(强证据:放量 + 主力净流入 + 机构加仓;证伪:若午后跌破 8.85 且主力转流出则降级为洗盘)
**归因**:板块 β 正向(商业零售 +2.27%)+ 个股 α(业绩快报超预期)+ 主力资金确认 + 情绪偏暖。
**综合**:板块+业绩双驱动,资金尾段现分歧,炸板是唯一减分项。

## 七、驱动因素(近 5 日)
[07-27] 消费政策快讯(P1)→ [07-28] 业绩快报 +7.15%(P0)→ 今日 9:38 涨停(资金行为)

## 八、关键位置
| 锚点 | 位置 | 现价偏离 |
|------|------|---------|
| 机构成本 | 8.20 | +11% |
| 融资盘成本 | 8.6-8.9 | +2.5% |
| MA20 | 8.85 | +3.1% |
| BOLL 上轨 | 9.38 | -2.8% |
现价 9.12 距 BOLL 上轨最近,上方压力 9.38,下方支撑 8.85(MA20 与融资成本上沿共振)。

## 九、风险清单
- 融资拥挤度 90% 分位(中高风险,见第四章)
- 炸板分歧(今日,短期情绪风险)
- 解禁/减持/质押:未发现

## 十、资讯/公告汇总
[P0] 业绩快报 7 月 28 日 +7.15%(已消化)→ [P1] 消费政策(板块联动中)

## 十一、午后观察点
1. 午后量能能否维持(来源:盘中行情)→ 维持+重新封板=拉升延续;缩量回落=分歧消化中
```
