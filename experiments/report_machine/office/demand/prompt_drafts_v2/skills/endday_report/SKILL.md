# 日终收盘分析报告 Skill

## 触发条件

当用户要求生成「日终收盘分析报告」时,使用本 skill。

## 报告定位

日终报告是投资者的**完整分析需求**:晚间复盘今日全貌 + 制定次日计划。与午间报告的分工:
- **日终**(18:30 后阅读)= 完整归因 + 次日作战计划(慢慢读)
- **午间**(盘中阅读)= 当日触发校验 + 午后 2 小时决策(快速读)

日终报告的数据优势:龙虎榜为当日(T)实锤数据,涨停/炸板为当日盘后数据,全日资金流/行情完整——这是与午间报告最大的区别,必须充分利用。

**分析为骨,数据为证**:输出的是分析判断,数据只作为证据引用——报告不是数据堆叠,每个数字必须服务于某个判断。

## 核心分析方法(依据《个股资金博弈分析框架》+《日终报告需求文档》)

分析骨架是**四步法**:① 盘面定调 → ② 分角色资金拆解(主力/游资/散户)+ 杠杆 + 机构 → ③ 资金阶段判断 + 涨跌归因 → ④ 条件式决策与风险清单。

**写作铁律(每一条都必须遵守)**:
1. **章节标题是分析问题,不是数据类型**(如"谁在买卖"而非"资金流向数据")
2. **禁止独立数据表格**:数据只能内嵌在分析句子里作为证据引用("龙虎榜机构专用 2 席净买 1.2 亿,买一集中度 55%")。唯一例外:技术面章的成本地图四锚点小表
3. **先结论后证据**:每段第一句是判断,数据在后支撑
4. **没有结论的数据不出现**:报告里出现的每个数字必须服务于某个判断,不服务于判断的数字不写
5. **缺数据必须坦白**:写"缺少 XX 数据,无法判断 Y"
6. **证据分三档**:实锤(龙虎榜席位/公告/大宗营业部)> 强证据(价量资金共振)> 弱迹象(单指标)
7. **每个数据块标注日期**(今日/T-1/报告期),严禁混用
8. **阶段判断必须附证伪条件**;决策必须条件式(如果 X 则 Y)
9. **数据日期探测**:T 日数据缺失时脚本会回退 T-1 并标注——引用时以标注日期为准,不得把 T-1 数据说成今日

## 数据来源(取数脚本 fetch_endday_data 的节 → 报告用在哪)

| 脚本数据节 | 报告用在哪里 |
|---|---|
| 全市场情绪 | 全市场环境参考 |
| 今日收盘行情 | 一、今日收盘行情(盘面定调) |
| 融资融券多日(T-1,250日) | 三、融资融券多日分析 |
| 龙虎榜(T 日) | 二、游资(T 日实锤,日终独有) |
| 个股资金流(moneyflow T日/回退 + 雪球) | 二、主力/散户 |
| 机构持仓 / 机构调研 | 四、机构行为 |
| 股东户数 | 二、散户 |
| 风险日历(解禁/质押/披露) | 八、风险清单 |
| 涨停/炸板(盘后) | 二、游资 + 八、风险(游资退潮) |
| 板块排名/基准 | 五、涨跌归因(板块 β) |
| 技术面+成本地图(收盘) | 七、技术面与成本地图 |
| 业绩趋势 | 九、业绩趋势 |
| 公告补充 | 六、驱动因素时间线 + 十、资讯 |
| 大宗交易(近5日,实锤) | 二、主力/游资(席位定性) + 五、阶段判断 + 七、成本锚 + 八、风险清单 |

**大宗交易分析规则(实锤级证据,印证工具非触发工具)**:
- 席位定性: 买/卖含"机构专用" → 归入主力小节, 与机构持仓趋势交叉验证; 营业部实名 → 归入游资小节, 与龙虎榜席位交叉(同席位多次出现=同一资金连续动作)
- 折溢价: >5% 大幅折价=卖方急于变现(偏空); 平价/溢价=买方抢筹(偏多); 折价越大, 接盘方短线兑现动机越强
- 规模: 单笔小额(<500万)为噪音, 不参与判断; 连续多日大宗或单笔大额(占流通盘显著)才升级为证据
- 事件关联: 减持/解禁公告同期的大宗 = 减持通道实锤(最强信号, 写入风险清单)
- 成本锚: 大宗成交价 ≈ 接盘方成本, 可与机构成本/融资成本交叉验证(多个锚点同区间=强支撑/压力)
- **证据强度**: 减持公告+大宗流出=实锤 | 连续大额+席位一致+资金流共振=强证据 | 单笔折价/溢价=弱迹象
- **禁止**: 仅凭"有大宗交易"断言主力进出; 无大宗=常态(低频事件), 不得写成风险

## 一、今日收盘行情(盘面定调)

**分析问题**:今日价格行为什么形态?量能配合?收在什么位置?

- 结论先行:一段话概括收盘形态(高开低走/低开高走/冲高回落/窄幅震荡/收于高位/中段/低位)
- 量能:换手/量比/振幅,放量还是缩量,与昨日对比
- 位置:收盘价在日内高低区间的位置(结合日内位置占比)

> 本节只陈述事实与量价配合,不下买卖结论。

---

## 二、谁在买卖(分角色资金拆解,核心章节)

> 规则:每个角色独立分析段。**数据齐时给出解读;数据缺失时写"缺少 XX 数据,无法判断",严禁强行推断。**

### 2.1 主力在做什么?

**分析问题**:主力多日方向?强度?时段结构说明什么?

- 结论先行:主力[净流入/流出]方向 + 3/5/10 日累计趋势 + 资金强度(净额/成交额)
- 时段结构(雪球):早盘/午盘/尾盘净额——尾盘抢筹=资金意愿强
- 结合融资余额方向(T-1)与股东户数(报告期)佐证

### 2.2 游资有什么动静?(日终独有最强数据)

**分析问题**:当日游资/机构在做什么?涨停基因如何?

- 龙虎榜(T 日,实锤):上榜原因定性异动性质(涨幅偏离/换手异常/连续三日/振幅)
- 席位构成:机构专用多=机构行情;营业部多=游资行情;买一集中度=单一游资控盘
- 涨停基因:首封越早越强、封单/流通市值越大越难砸、开板次数多=分歧大
- 连板状态 + 昨日涨停今日溢价 → 接力意愿 or 一日游
- **未上榜时明确写"今日未上龙虎榜,无法从席位层面确认游资动向"**

### 2.3 散户在接盘还是割肉?

**分析问题**:散户方向与筹码状态?

- 小单 5 日净额方向 + 股东户数变化
- 散户接盘(小单流入+价滞涨)= 出货阶段确认;散户割肉+价企稳 = 筹码转移迹象;股东户数暴增=阶段顶部特征(弱迹象)

---

## 三、融资融券多日分析(杠杆章)

**分析问题**:杠杆资金在加仓还是撤退?拥挤到什么程度?融资盘成本在哪?

数据来源:融资融券多日(T-1,250 日序列)。核心三项必分析:
1. **杠杆方向**:融资余额 5/10/20 日趋势 + 净买入(买入-偿还)方向
2. **杠杆拥挤度**:余额÷流通市值,近一年分位(>80% 高拥挤;>80% + 价格下跌 = **强平负反馈风险预警**,重点风险提示)
3. **融资盘成本区 vs 现价**:现价上方=融资盘浮盈;现价跌破成本区=融资盘被套,强平踩踏风险区

派生三项有信号才写:量价背离(余额升+价不涨=杠杆接盘风险;余额降+价企稳=去杠杆尾声健康)、买卖结构(rzmre 骤放=追涨情绪)、融券方向(弱信号)。

---

## 四、机构行为(机构章)

**分析问题**:机构成本锚在哪?机构在加仓还是撤退?

数据来源:机构持仓(同花顺 F10)+ 机构调研(近180天)。
- **机构成本估算 vs 现价**:上方=机构浮盈(获利了结压力,但机构拿得住);下方=机构浮亏(深套锁仓 or 止损调仓)——**机构成本区是中期定价锚**,现价在成本下方不远=中期支撑参考
- 占比多期趋势:持续下降=机构撤退(高位风险);上升=加仓(信心)
- 新进/减持结构:**区分主动基金 vs 被动 ETF**(新进多为主动型=机构主动买入;减持多为被动 ETF=指数调仓,不等于看空)
- 调研频次骤增=机构关注度上升(弱证据,前瞻信号)

---

## 五、资金阶段判断 + 涨跌归因

### 5.1 资金阶段判断

**分析问题**:当前处于吸筹/洗盘/拉升/出货哪个阶段?

| 阶段 | 判定条件 | 当前是否成立 | 证据 |
|------|---------|:---:|------|
| 吸筹 | 横盘/阴跌 + 大单持续净流入 + 量缩 | | |
| 洗盘 | 回调缩量 + 大单不流出 + 不破关键均线 | | |
| 拉升 | 放量上涨 + 主力净流入 + 板块配合 | | |
| 出货 | 滞涨/冲高回落 + 大单流出 + 散户接盘 | | |

**结论**:[判断或"数据不足无法判断"] | **证伪条件**:[必写] | **证据强度**:[实锤/强证据/弱迹象]

### 5.2 涨跌归因(四因子)

- **板块因素(β)**:[所属板块今日涨 X%,个股跑赢/跑输 X 个百分点]
- **个股因素(α)**:[业绩/公告/事件,引用具体公告]
- **资金因素**:[谁在主导——主力/游资/散户、杠杆/机构方向]
- **情绪因素**:[大盘与市场热度背景]

**综合结论**:[一句话归因 + 主次排序 + 证据强度标注,如"板块 β+业绩 α 双驱动,主力尾盘确认,但游资未上榜确认"]

## 十一、综合判断(报告灵魂,必须完整输出)

### 11.1 归因总结
[今日盘面由什么主导——一句话 + 主次排序,引用前文各章证据]

### 11.2 盘面含义
[对投资者意味着什么:现价位置(成本地图)× 资金阶段 × 杠杆/机构状态 → 风险收益特征]

### 11.3 后市关键观察点(3-5 个)+ 决策倾向
每个观察点必须包含:**具体信号 + 数据来源 + 预计出现时间 + 条件式决策倾向**。示例:
1. [融资余额占比是否回落](来源:融资融券 T-1 数据,明日可得)→ 若从 90% 分位回落=风险偏好修复,倾向持有;若继续攀升+价格滞涨=杠杆堆积,倾向减仓
2. [是否出现游资接力](来源:龙虎榜,明日 17:30)→ 若现知名游资买入=短线情绪确认,倾向持有;若机构卖出=趋势资金撤退,倾向观望
3. [放量突破/跌破关键位](来源:盘中行情)→ 突破 X.XX 且主力净流入=拉升启动,倾向买入;跌破 X.XX 且主力流出=阶段判断失效,倾向卖出
4. [主力资金 3 日方向](来源:资金流,次日盘后)→ ...

> 这些观察点是**次日午间报告的触发校验输入**——次日盘中逐条校验是否被触发。
