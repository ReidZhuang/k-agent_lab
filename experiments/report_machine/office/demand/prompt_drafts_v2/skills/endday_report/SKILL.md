## 核心分析方法(依据《个股资金博弈分析框架》+《日终报告需求文档》)

分析骨架是**四步法**:① 盘面定调 → ② 分角色资金拆解(主力/游资/散户)+ 杠杆 + 机构 → ③ 资金阶段判断 + 涨跌归因 → ④ 条件式决策与风险清单。

**全局纪律**(每一条都必须遵守):
- 每个数据块标注日期(今日/T-1/报告期),严禁混用
- 证据分三档:实锤(龙虎榜席位/公告/大宗营业部)> 强证据(价量资金共振)> 弱迹象(单指标)
- 缺数据必须坦白:写"缺少XX数据,无法判断Y"
- 阶段判断必须附证伪条件
- 决策必须条件式(如果X则Y)
- **日终报告的数据优势**:龙虎榜为当日(T)实锤数据,涨停/炸板为当日盘后数据——这是与午间报告最大的区别,必须充分利用

## 二、分角色资金拆解(核心章节)

> 规则:每个角色独立小节。**数据齐时给出解读;数据缺失时写"缺少XX数据,无法判断",严禁强行推断。**

### 2.1 主力(机构/大资金)

**数据呈现**(注明日期):

| 指标 | 数据 | 日期 |
|------|------|------|
| 主力净额(超大单+大单) | 3日/5日/10日累计 | T日或T-1(按标注) |
| 主力资金强度(净额/成交额) | X.X% | 对应日期 |
| 主力净额逐日 | 近10日序列 | 逐日 |
| 今日时段结构 | 早盘/午盘/尾盘净额 | T日 |
| 融资余额方向 | 5/10/20日变化 | T-1 |
| 股东户数变化 | 最新期较上期 | 报告期 |

**解读**:多日趋势 + 时段结构(尾盘抢筹=资金意愿强)+ 资金强度;与价格的关系。

### 2.2 游资(日终独有最强数据)

**数据呈现**(注明日期):

| 指标 | 数据 | 日期 |
|------|------|------|
| 龙虎榜上榜 | 上榜原因、涨跌幅、换手率 | T日 |
| 龙虎榜净买入 | 净买/买入/卖出额 | T日 |
| 买方席位构成 | 前5席位明细 + 机构专用席位数 | T日 |
| 买一集中度 | 买一席位占买方净额比 | T日 |
| 卖方席位 | 前3席位 | T日 |
| 涨停/炸板 | 首封时间、开板次数、封单、连板、涨停原因 | T日 |
| 昨日涨停今日表现 | 涨跌幅、状态 | T日 |

**解读**:
- 上榜原因定性异动性质(涨幅偏离/换手异常/连续三日/振幅)
- 席位构成:机构专用多=机构行情;营业部多=游资行情;买一集中=单一游资控盘
- 涨停基因:首封越早越强、封单/流通市值越大越难砸、开板次数多=分歧大
- 连板状态 + 昨日涨停今日溢价 → 接力意愿 or 一日游
- **未上榜时明确写"今日未上龙虎榜,无法从席位层面确认游资动向"**

### 2.3 散户

**数据呈现**:小单 5 日净额 + 股东户数变化。

**解读**:散户接盘(小单流入+价滞涨)= 出货阶段确认;散户割肉+价企稳 = 筹码转移迹象。股东户数暴增=阶段顶部特征(弱迹象)。

## 三、融资融券多日分析(杠杆章)

**数据呈现**(T-1 日数据,250日序列计算):

| 指标 | 数据 |
|------|------|
| 融资余额 | X.XX亿(5/10/20日变化%) |
| 融资净买入(买入-偿还) | 5日/20日累计 |
| 杠杆拥挤度(余额÷流通市值) | X.X%,近一年分位 X%(>80%高拥挤) |
| 融资盘成本区 | X.XX-X.XX元(加权成本) |
| 现价 vs 成本区 | 上方/之内/下方 |
| 融券余额 | X.XX亿(20日变化%) |
| 量价关系 | 同向/背离 |

**解读规则**:
- 杠杆方向:净买入持续为正=杠杆加仓;为负=去杠杆
- 拥挤度 >80% 分位 + 价格下跌 = **强平负反馈风险预警**(重点风险提示)
- 现价跌破融资盘成本区 = 融资盘被套,强平踩踏风险区
- 背离:余额升+价不涨=杠杆盘接盘(风险);余额降+价企稳=去杠杆尾声(健康)
- 融资买入额骤放=杠杆追涨情绪(情绪拐点信号)

## 四、机构行为(机构章)

**数据呈现**:

| 报告期 | 基金占比% | 对应股价 | 环比 |
|---|---|---|---|
| (近6期趋势表) | | | |

- 机构持仓成本估算(近4期占比加权):X.XX元
- 最新期明细:共N条 | 新进A只 | 减持B只
- 新进/增持/减持前5(名称+金额)
- 机构调研:近180天月度频次 + 最近记录(机构名/方式)

**解读规则**:
- 现价 vs 机构成本:上方=机构浮盈(获利了结压力,但机构拿得住);下方=机构浮亏(深套锁仓 or 止损调仓)
- **机构成本区是中期定价锚**:现价在成本下方不远=中期支撑参考
- 占比 8 期趋势:持续下降=机构撤退(高位风险);上升=加仓(信心)
- 新进/减持结构:新进多为主动型基金=机构主动买入;减持多为被动ETF=指数调仓(区分主动/被动!)
- 调研频次骤增=机构关注度上升(弱证据,前瞻信号)
