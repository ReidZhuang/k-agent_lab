# 午间收盘分析报告 Skill

## 触发条件

当用户要求生成「午间收盘分析报告」时,使用本 skill。

## 报告定位(最重要,先读)

**午间报告是决策触发型工具,不是日常报告。** 投资者只在两种日子看:
1. **行情特别好的日子**——想追涨/加仓,怕踏空(进攻性决策)
2. **个股买卖急迫的关键日子**——要决定下午卖不卖/该不该买(防守或出手决策)

两种场景的共同点:**决策窗口只有下午 2 小时**。因此:
- 报告开头必须在 **30 秒内让读者判断"有事没事"**(三问直答)
- 有事再花几分钟读证据层(完整分析,与日终同构)
- **分析为骨,数据为证**:输出的是分析判断,数据只作为证据引用——上一版失败原因就是数据堆叠,读者认为"没用"

## 核心分析方法(依据《个股资金博弈分析框架》+《午间报告需求文档》)

分析骨架是**四步法**:① 盘面定调 → ② 分角色资金拆解(主力/游资/散户)+ 杠杆 + 机构 → ③ 资金阶段判断 + 上午涨跌归因 → ④ 条件式午后观察点与风险清单。

**写作铁律(每一条都必须遵守)**:
1. **章节标题是分析问题,不是数据类型**(如"主力上午在做什么?"而非"资金流向数据")
2. **禁止独立数据表格**:数据只能内嵌在分析句子里作为证据引用("尾盘 30 分钟净流入 2.4 亿,占半日成交 3.2%")。唯一例外:关键位置章的成本地图四锚点小表
3. **先结论后证据**:每段第一句是判断,数据在后支撑
4. **没有结论的数据不出现**:报告里出现的每个数字必须服务于某个判断,不服务于判断的数字不写
5. **缺数据必须坦白**:写"缺少 XX 数据,无法判断 Y"
6. **证据分三档**:实锤(龙虎榜席位/公告/大宗营业部)> 强证据(价量资金共振)> 弱迹象(单指标)
7. **每个数据块标注日期**(今日半日/T-1/报告期),严禁混用
8. **当日龙虎榜未出**(T 日 17:30 后才有)→ 游资章节必须写"当日游资动向待盘后确认",不得用 T-1 数据冒充
9. **阶段判断必须附证伪条件**;建议必须条件式(如果 X 则 Y)
10. **数据日期探测**:T 日数据缺失时脚本会回退 T-1 并标注——引用时以标注日期为准,不得把 T-1 数据说成今日

## 一、早盘发生了什么(盘面定调)

**分析问题**:上午强势/弱势/震荡?量能配合还是背离?收在什么位置?

- 结论先行:一段话概括上午的价格行为与量能特征
- 位置:现价在日内高低区间的什么位置(结合半日收盘位置)
- 放量/缩量对比(半日换手 vs 昨日全天换手)

> 本节只陈述事实与量价配合,不下买卖结论。

---

## 二、有没有异常(异常扫描,午间独有核心)

**分析问题**:上午有没有异常?异常意味着什么?需不需要行动?

逐项判断(数据来源:盘中异动/跌停/快讯 + 龙虎榜 T-1 + 融资拥挤度 + 破位):
- 盘中异动(封涨停/打开涨停/火箭发射/大笔买卖等)——[有/无],有则解释
- 炸板/跌停/快速跳水——[有/无],有则解释
- P0 级快讯突发——[有/无],有则解释对下午的影响
- T-1 龙虎榜大卖——[有/无]
- 融资拥挤度异常(>80% 分位 + 放量下跌)——[有/无]
- 破位关键均线(MA5/MA10/MA20)——[有/无]

全部无异常时,输出一行"未发现异常"。有异常时,每个异常:是什么 + 意味着什么 + 是否需要行动。

## 三、谁在买卖(分角色分析)

### 3.1 主力上午在做什么?

**分析问题**:主力方向?强度?时段结构说明什么?

- 结论先行:主力[净流入/净流出]方向 + 强度判断
- 时段结构:早盘 9:30-10:00 / 10:00-11:00 / 11:00-11:30 的净额分配(拉升段 vs 尾段撤退)
- 结合 T-1 角色结构(大单/中单/小单)推断连续性
- **注意局限**:今日盘中资金流是总量曲线,不分角色——无法确认今日主力角色的部分要坦白

### 3.2 游资有什么动静?

**分析问题**:T-1 游资/机构在做什么?今日盘中有什么迹象?

- T-1 龙虎榜(实锤,标注 T-1):上榜原因定性、席位构成(机构专用 vs 营业部)、买一集中度
- 今日盘中:涨停/封单/开板/异动(迹象级)——首封早=意愿强,开板次数=分歧度
- **必须写明**:"当日龙虎榜未出,当日游资动向待盘后确认"

### 3.3 散户在接盘还是割肉?

**分析问题**:散户方向与筹码状态?

- T-1 小单净额方向 + 股东户数变化(集中/分散)
- 散户接盘+价滞涨 = 出货阶段确认(配合 3.1/3.2);割肉+价企稳 = 筹码转移迹象

---

## 四、杠杆资金怎么看(融资融券多日,与日终同等级)

**分析问题**:杠杆资金在加仓还是撤退?拥挤到什么程度?融资盘成本在哪?

数据来源:融资融券多日(T-1,250 日序列)。核心三项必分析:
1. **杠杆方向**:融资余额 5/10/20 日趋势 + 净买入方向
2. **杠杆拥挤度**:余额÷流通市值,近一年分位(>80% 高拥挤 → 风险提示;>80% + 价格下跌 = **强平负反馈风险预警**,重点提示)
3. **融资盘成本区 vs 现价**:现价上方=融资盘浮盈;跌破成本区=融资盘被套,强平踩踏风险区

派生三项有信号才写:量价背离(余额升+价不涨=杠杆接盘风险)、买卖结构(rzmre 骤放=追涨情绪)、融券方向(弱信号)。

---

## 五、机构在干什么(机构行为,与日终同等级)

**分析问题**:机构成本锚在哪?机构在加仓还是撤退?

数据来源:机构持仓(同花顺 F10)+ 机构调研(近180天)。
- **机构成本估算 vs 现价**:上方=机构浮盈;下方=机构浮亏(深套锁仓 or 止损调仓)——中期定价锚
- 占比多期趋势:持续下降=机构撤退(高位风险);上升=加仓(信心)
- 新进/减持结构:**区分主动基金 vs 被动 ETF**(减持多为被动 ETF=指数调仓,不等于看空)
- 调研频次骤增=机构关注度上升(弱证据,前瞻信号)

| 出货 | 滞涨/冲高回落 + 大单流出 + 散户接盘 | | |

### 6.2 上午涨跌归因(四因子)

- **板块因素(β)**:[所属板块今日涨 X%,个股跑赢/跑输 X 个百分点]

## 十一、午后观察点 + 顺着逻辑的小建议

### 11.1 午后关键观察点(3-5 个)

每个观察点必须包含:**具体信号 + 数据来源 + 预计出现时间 + 条件式判断**。示例:
1. [午后量能能否维持](来源:盘中行情)→ 维持+重新封板=拉升延续;缩量回落=分歧消化中
2. [主力资金方向是否扭转](来源:盘中资金流,收盘后确认)→ 尾盘净流入=资金确认;持续流出=阶段判断降级
3. [是否放量突破/跌破关键位](来源:盘中行情)→ 突破 X.XX 且主力净流入=拉升启动;跌破 X.XX=阶段判断失效
4. [板块是否维持强势](来源:板块排名)→ 板块走弱+个股放量下跌=补跌风险

### 11.2 前日日终观察点触发校验

优先校验**前一日日终报告**的观察点是否被触发——被触发/未触发的分别说明,这决定今日行动是否有据。

### 11.3 顺着逻辑的小建议(1-2 句)

全篇分析结束后,顺着逻辑给条件式倾向(非指令):"若午后 X 则持有逻辑成立;若 Y 失守则今日不宜加仓"。
