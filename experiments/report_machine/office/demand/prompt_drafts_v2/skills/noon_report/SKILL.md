## 核心分析方法(依据《个股资金博弈分析框架》)

分析骨架是**四步法**:① 盘面定调 → ② 分角色资金拆解(主力/游资/散户)→ ③ 资金阶段判断 + 涨跌归因 → ④ 条件式决策与风险清单。

**全局纪律**:
- 每个数据块标注日期(今日午间/T-1/报告期),严禁混用
- 证据分三档:实锤(龙虎榜席位/公告)> 强证据(价量资金共振)> 弱迹象(单指标)
- 缺数据必须坦白:写"缺少XX数据,无法判断Y"
- 阶段判断必须附证伪条件
- 决策必须条件式(如果X则Y)
- **午间数据局限(必须遵守)**:龙虎榜为**昨日(T-1)**数据(当日榜 17:30 后才出);盘中资金流只有总量曲线(无分角色);融资融券为 T-1 单日——报告不得把昨日数据说成今日,不得在无数据时编造当日龙虎榜/游资席位

## 二、分角色资金拆解

### 2.1 主力(机构/大资金)

**数据呈现**(注明日期):

| 指标 | 数据 | 日期 |
|------|------|------|
| 今日午间资金净流向(总量) | [净流入/流出] X.XX亿 | 今日 |
| 流入/流出分钟比 | X分钟 / X分钟 | 今日 |
| 最大单分钟流入/流出 | X / X 万 | 今日 |
| 昨日大单净额 | X.XX亿 | T-1 |
| 昨日中单净额 | X.XX亿 | T-1 |
| 昨日小单净额 | X.XX亿 | T-1 |
| 融资余额 | X.XX亿(较前日±X.X%) | T-1 |

**解读**:今日总量方向 + 昨日角色结构 + 融资方向;注意"今日盘中总量不分角色,无法确认今日主力方向"的局限。

### 2.2 游资

**数据呈现**(注明日期):

| 指标 | 数据 | 日期 |
|------|------|------|
| 龙虎榜上榜(昨日) | 上榜原因、净买额 | T-1 |
| 席位构成 | 机构专用/营业部、买一集中度 | T-1 |
| 涨停信息(今日盘中,如有) | 首封时间、开板次数 | 今日 |
| 连板状态 | N连板 | 今日 |
| 异动监测(今日) | 大笔买入/大笔卖出/火箭发射等 | 今日 |

**解读**:
- 昨日龙虎榜席位定性昨日资金性质(机构 vs 游资)
- 今日盘中涨停/异动监测:首封早=意愿强;大笔买入时间点与价格低点关系=承接
- **今日盘中无法获取当日龙虎榜——若需确认当日游资行为,明确写"当日龙虎榜未出,游资动向待盘后确认"**

### 2.3 散户

**数据呈现**:昨日小单净额 + 股东户数(如有)。

**解读**:散户接盘/割肉方向 + 筹码集中度(弱迹象)。

| 拉升 | 放量上涨 + 大单净流入 + 板块配合 | | |
| 出货 | 滞涨/冲高回落 + 大单流出 + 散户接盘 | | |

**结论**:[判断或"数据不足无法判断"] | **证伪条件**:[必写] | **证据强度**:[实锤/强证据/弱迹象]

### 3.2 涨跌归因

- **板块因素(β)**:[板块涨X%,个股跑赢/跑输]

- **资金因素**:[今日净流向 + 昨日角色结构]
- **情绪因素**:[大盘与市场热度]

**综合结论**:[一句话归因 + 证据强度]

### 8.3 午后关键观察点(3-5个)+ 决策倾向

1. [午后是否放量突破/跌破关键位](来源:盘中行情)→ 突破X.XX且放量=拉升启动,倾向持有;跌破X.XX=阶段判断失效,倾向减仓
2. [主力资金方向是否扭转](来源:盘中资金流,收盘后确认)→ 尾盘净流入=资金确认,倾向持有;持续流出=观望
