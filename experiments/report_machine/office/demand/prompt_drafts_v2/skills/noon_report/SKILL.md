## 核心分析方法(依据《个股资金博弈分析框架》)

本报告的分析骨架是**四步法**:
① 盘面定调 → ② 分角色资金拆解(主力/游资/散户) → ③ 资金阶段判断 + 涨跌归因 → ④ 条件式决策与风险清单

**全局纪律**:
- 每个数据块标注日期(今日午间/昨日/T-2),不得混用
- 证据分三档:实锤(龙虎榜席位/公告/大宗营业部)> 强证据(价量资金共振)> 弱迹象(单指标)
- 缺数据必须坦白:写"缺少XX数据,无法判断Y",禁止用其他数据强行推断
- 阶段判断必须附证伪条件
- 决策必须条件式(如果X则Y)

## 二、分角色资金拆解(核心章节)

> **规则**: 每个角色独立成小节。**数据齐时给出解读;数据缺失时写"缺少XX数据,无法判断该角色动向",严禁用其他数据强行推断或编造。**

### 2.1 主力(机构/大资金)

**数据呈现**(注明各自日期):

| 指标 | 数据 | 日期 |
|------|------|------|
| 超大单+大单净额(今日盘中,如有分角色数据) | [净流入/流出] X.XX亿 | 今日午间 |
| 大单净额(昨日) | [净流入/流出] X.XX亿 | T-1 |
| 大单净额(近3-5日趋势,如有) | 逐日列出 | T-2~T-1 |
| 资金强度 = 主力净额÷成交额(如有) | X.X% | 对应日期 |
| 融资余额 | X.XX亿(较前日 ±X.X%) | T-1 |
| 股东户数(如有历史) | X.X万户,较上期 ±X% | 最近公告期 |
| 龙虎榜机构席位(昨日,如有) | 买方/卖方机构专用 X 席位,净买 X 万 | T-1 |
| 大宗交易(近5日,如有) | 笔数、折溢价率、买卖营业部 | 各交易日期 |

**解读**(按证据强度):
- 多日趋势:大单连续净流入/流出几天?价格配合如何?
- 融资盘:余额方向与价格方向的关系(同步=杠杆追涨;背离=杠杆盘风险)
- 散户筹码:户数方向(减少=集中,增加=分散)
- 机构实锤:龙虎榜机构席位/大宗营业部(实锤级证据优先引用)

### 2.2 游资(短线热钱)

**数据呈现**(注明各自日期):

| 指标 | 数据 | 日期 |
|------|------|------|
| 龙虎榜上榜(昨日,如有) | 上榜原因、净买额、买方前5构成 | T-1 |
| 席位性质 | 机构专用 N 席 / 营业部 N 席;买一集中度 | T-1 |
| 知名游资匹配(如有) | 匹配到的游资名(如赵老哥/章盟主等)与营业部 | T-1 |
| 涨停信息(今日盘中,如有) | 首封时间、开板次数、封单额/流通市值 | 今日 |
| 连板状态(如有) | N连板、晋级情况 | 今日 |
| 昨日涨停今日表现(如有) | 高开/低开、冲高回落/续涨 | 今日 |

**解读**:
- 上榜原因直接定性昨日异动性质(涨幅偏离/换手异常/振幅异常/连续三日)
- 席位构成区分机构行情 vs 游资行情;买一集中=单一游资控盘
- 首封时间早+封单大+不开板=资金意愿强;炸板/开板次数多=分歧
- **昨日龙虎榜游资买入、今日高开回落=一日游出货嫌疑;今日续强=资金认可接力**

### 2.3 散户(中小单)

**数据呈现**(注明各自日期):

| 指标 | 数据 | 日期 |
|------|------|------|
| 小单净额(昨日) | [净流入/流出] X.XX亿 | T-1 |
| 小单净额(近3-5日,如有) | 逐日列出 | T-2~T-1 |
| 股东户数 | X.X万户,较上期 ±X% | 最近公告期 |
| 换手率结构 | 高/中/低换手 | 今日 |

**解读**:
- 散户净买入+价格滞涨 = 接盘迹象(配合主力出货判断)
- 散户割肉+价格企稳 = 筹码转移迹象(配合主力吸筹判断)
- 股东户数暴增常是阶段顶部特征(弱迹象)
