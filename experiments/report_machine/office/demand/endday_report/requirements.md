# 日终收盘分析报告 — 需求文档 v1.0

> 本文档定义「日终收盘分析报告」的完备需求:每部分需要什么数据、从哪取、几点取、怎么分析、输出什么、范本如何。
> 配套方法论: `office/demand/analysis_framework.md`(四步法/可证伪规范/数据总表)。
> 本文档是 `data_fetch/endday/fetch_endday_data.py` 与 `prompts_deepseek/skills/endday_report/SKILL.md` 的开发依据。

## 〇、运行时间与数据时效矩阵

**运行时间**: 交易日 18:30(在 ETL 18:00 全量之后、龙虎榜 17:30 之后)。由 commander 第二份 config + 新 cron 触发。

**数据时效矩阵**(18:30 时点):

| 数据 | 实际日期 | 原因 |
|------|---------|------|
| 行情快照(DB) | T 日 | 18:00 ETL 全量写入收盘快照 |
| 龙虎榜 top_list/top_inst | **T 日** | 交易所 17:30 后发布(日终独有优势,午间只能看到 T-1) |
| 雪球 capital_flow/assort/history | T 日 | 盘后统计 |
| 涨停/炸板 kpl_list、涨停池 | T 日 | 盘后发布(探测,空则回退 T-1 并标注) |
| moneyflow 资金流 | 探测 T 日,空则 T-1 | Tushare 晚间更新,18:30 可能未出 |
| 融资融券 margin_detail | **T-1** | 交易所次日 8:30 更新 |
| daily_basic(换手/流通市值) | **T-1** | 同上市值 |
| 机构持仓(同花顺 F10) | 最新报告期 | 季度 |
| 机构调研/股东户数 | 最近公告日 | 事件型 |
| 解禁/质押/披露计划 | 事件日历 | 未来 90 天 |
| 财务趋势 fina_indicator | 最近已披露报告期 | 季度 |
| 公告/业绩快报 | 探测 T 日,空则 T-1 | Tushare 晚间更新 |
| 技术面 K线 | T 日 | 收盘后日线完整 |

**硬性纪律**: 任何数据块输出时附实际日期标签,严禁 LLM 混用日期。

## 一、报告结构(日终版四步法)

日终报告与午间共用四步法骨架,新增三大分析章(杠杆/机构/综合判断)与日终独有章节(龙虎榜、涨停炸板、筹码相关)。

### 每章的数据-分析-输出规格

### 0. 速览摘要
- **数据**: 全文各章结论
- **分析**: 条件式决策摘要(如果X则Y)+ 资金阶段判断(弱迹象级)+ 今日归因一句话
- **输出**: 固定格式 5 行(涨跌/跑赢跑输/驱动/资金/技术位置 + 阶段 + 操作含义 + 亮点)

### 1. 全市场环境参考
- **数据**: levistock market_emotion_cls/kph(收盘后)、大盘指数
- **取数**: 收盘后调用,市场热度/成交额/上涨占比/涨停梯队/涨跌分布
- **分析**: 只呈现不展开;为个股解读提供情绪背景
- **输出**: blockquote 格式,同午间

### 2. 今日收盘行情(盘面定调)
- **数据**: DB 最新快照(ETL 18:00 全量)
- **字段**: 收盘价/涨跌幅/开高低收/成交额/换手/量比/振幅/内外盘/PE/PB/市值/涨跌停价
- **分析**: 价格行为 + 量能 + 位置的事实陈述(不下判断)
- **输出**: 表格 + 盘中形态描述(结合最高最低与收盘位置)

### 3. 分角色资金拆解(核心)

#### 3.1 主力
- **数据**:
  - moneyflow 20 日(小/中/大/超大单买卖额)→ 主力=超大+大单
  - 雪球 capital_history 20 日(日净额 + 自算 3/5/10 日累计)
  - 雪球 capital_flow(当日逐分钟 → 时段拆分: 早盘/午盘/尾盘净额,尾盘 14:30-15:00)
  - 融资融券多日(见章 4)
- **分析**:
  - 5/10 日主力净流入趋势 + 资金强度(净额/成交额)
  - 时段结构: 尾盘抢筹 vs 早盘出货
  - 阶段判断证据(吸筹/洗盘/拉升/出货)
- **输出**: 表格(逐日主力净额 + 3/5/10日累计 + 强度)+ 时段表 + 解读

#### 3.2 游资(日终独有,最强章节)
- **数据**:
  - Tushare top_list(T 日): 上榜原因/净买额/买卖前5
  - Tushare top_inst(T 日): 机构专用 vs 营业部席位、买一集中度
  - Tushare kpl_list(T 日): 涨停时间/开板/连板/封单/涨停原因
  - levistock stock_yesterday_zt_em: 昨日涨停今日表现
  - 游资名单匹配(hm_list 如积分可用)
- **分析**:
  - 上榜原因定性当日异动性质
  - 席位构成: 机构行情 vs 游资行情;买一集中度
  - 涨停基因: 首封时间/封单强度(封单/流通市值)/开板次数
  - 昨日涨停今日溢价 → 一日游识别
- **输出**: 龙虎榜表(席位/金额/集中度)+ 涨停数据表 + 游资解读

#### 3.3 散户
- **数据**: moneyflow 小单 20 日、股东户数(最近两期变化)
- **分析**: 散户接盘/割肉方向、筹码集中/分散
- **输出**: 表格 + 一行解读

### 4. 融资融券多日分析(杠杆章,新增)
- **数据**: Tushare margin_detail **250 日**(rzye/rzmre/rzche/rqye/rqmcl)+ daily_basic 250 日(流通市值/收盘价)
- **分析**(6 切入点,核心3必填+派生3有信号才写):
  1. 杠杆方向: 融资余额 5/10/20 日趋势 + 净买入(买入-偿还)方向
  2. **杠杆拥挤度**: 融资余额÷流通市值,近一年分位(>80% 高拥挤,<20% 低拥挤)
  3. **融资盘成本区**: 融资余额净增密集价格区间(按净增额加权)≈ 融资盘成本;现价 vs 成本
  4. 背离: 余额升+价不涨=杠杆接盘(风险);余额降+价企稳=去杠杆尾声
  5. 买卖结构: rzmre 骤放=追涨情绪;rzche 骤放=撤退
  6. 融券: rqye 方向(弱信号)
- **输出**: 趋势表(5/10/20日变化)+ 拥挤度(分位)+ 成本区间 + 风险提示(强平负反馈预警)

### 5. 机构行为(机构章,新增)
- **数据**:
  - 同花顺 F10 org_holder 4 端点: rate(8期汇总)/tab(类型占比)/detail(最新期基金明细)/rate_price(基金占比+股价)
  - Tushare stk_surv 近 180 天(调研频次/机构名单/接待方式)
- **分析**:
  - 机构持仓比例 8 期趋势(加仓/减仓)
  - 最新期: 新进+增持合计 vs 减持合计(金额)
  - 知名基金进出(明细前 20 条 + 变化金额最大的)
  - **机构成本估算**: 用 rate_price 的"基金占比+对应股价"序列加权,或用明细持股数×报告期均价近似;现价 vs 机构成本(浮盈/浮亏)
  - 调研频次: 近 180 天按月分布,骤增=关注度上升(弱证据)
- **输出**: 汇总表(8期)+ 明细摘要(前10增持/前10减持)+ 成本估算 + 调研表

### 6. 股东户数(筹码慢变量)
- **数据**: Tushare stk_holdernumber 最近 4 期
- **分析**: 户数增减方向 → 筹码集中/分散(配合主力/散户判断)
- **输出**: 表格 + 一行解读

### 7. 涨跌归因判断
- **数据**: 2-6 章 + 8-10 章 + 消息章
- **分析**: 四因子归因——板块β(个股 vs 板块)/个股α(业绩/公告)/资金性质(谁主导)/情绪环境;标注主次与证据强度
- **输出**: 结构化归因(分因子一句话 + 综合结论)

### 8. 驱动因素(事件面,近 5 日时间线)
- **数据**: 财联社快讯(levistock)+ 公告(补充信息章)+ 热门板块原因 + 资讯文章(mail_tower)
- **分析**: P0/P1/P2 分层;标注与价格的时间关系(事件-价格联动)
- **输出**: 时间线列表(时间/事件/层级/影响)

### 9. 技术面与成本地图(新增"成本地图")
- **数据**: 新浪K线(当日完整,直接用最近 20 日)、MA5/10/20/BOLL
- **成本地图**: 现价 vs MA20 vs 机构成本(章5) vs 融资盘成本(章4)——四个"心理价位"一览
- **输出**: 技术指标表 + 成本地图表(4 个锚点 + 现价相对位置)

### 10. 风险清单
- **数据**: share_float(未来 90 天解禁)/ pledge_stat(最新质押比例)/ disclosure_date(未来 90 天披露计划)/ stk_holdertrade(增减持)/ 融资拥挤度(章4)/ 炸板连板失败(章3.2)/ 高位获利盘(章9)
- **分析**: 逐项检查,存在则量化,无则"未发现"
- **输出**: 风险表(风险项/状态/量化/说明)

### 11. 业绩趋势(中期归因)
- **数据**: fina_indicator 最近 4-8 期(eps/roe/毛利率/净利率/资产负债率)+ 业绩快报/预告
- **分析**: 同比环比趋势;业绩驱动型 vs 资金驱动型区分
- **输出**: 趋势表 + 一行结论

### 12. 资讯/公告汇总
- **数据**: mail_tower 5 引擎(sinafin/baidufin/thsfin/juchao/qnainfo)
- **分析**: P0/P1/P2 分层,逐条标注来源与时间
- **输出**: 分层列表(同午间)

### 13. 综合判断(汇总章,新增,报告灵魂)
- **分析**:
  1. 归因总结: 今日盘面由什么主导(一句话 + 主次排序)
  2. 盘面含义: 对投资者意味着什么(现价位置 × 资金阶段 × 杠杆/机构状态 → 风险收益特征)
  3. **后市关键观察点(3-5 个)+ 决策倾向**: 每个观察点 = 具体信号 + 数据来源 + 出现时间 + "如果X则倾向Y"
- **输出**: 三段式固定结构

### 14. 完整度自评
- 完整度(高/中/低)+ 信息缺失项 + 数据缺口对结论的影响(哪些结论降级为弱证据)
