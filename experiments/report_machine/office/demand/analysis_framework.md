# 个股资金博弈分析框架(方法论总纲)

> **本文档的定位**: 这是报告系统的"宪法"——定义分析什么、为什么可分析、需要什么数据、怎么分析、如何证伪。
> 后期所有 prompt(soul / agent / preference / skill)均由本文档推演而来,任何 prompt 不得与本文档冲突。
>
> **读者**: 系统设计者(投资小白)+ 未来的 LLM。因此本文档同时承担"投资知识教学"和"分析规则定义"两个职责。

---

## 〇、核心结论(先看这个)

1. **分析目标**: 回答四件事——① 主力/游资/散户今天都做了什么;② 这些操作与当前盘面的关系;③ 这表现了什么逻辑(处于什么阶段);④ 对买入卖出决策意味着什么。
2. **分析哲学**: 只做"有证据的判断",所有判断必须能列出**支持证据**和**证伪条件**。没有证据时说"无法判断",不许编造。
3. **现状**: 数据基本齐备(见第四节)。最大缺口是"游资识别"(龙虎榜),已找到免费来源;次大缺口是"资金持续性"(1/3/5日),已找到现成接口。
4. **红线**: 资金流是**同步指标**,不是预言机。它回答"谁在买",回答不了"明天涨不涨"。报告的决策价值在于**条件式结论**(如果X则Y)和**风险信号**,不在于涨跌预测。

---

## 一、投资基础:三类玩家

A股市场每笔交易都是两个人对赌(你买我卖)。要分析"资金博弈",先理解市场上三类主要玩家及其行为特征:

| 玩家 | 是谁 | 资金量 | 持股周期 | 典型行为 | 可观测代理 |
|------|------|--------|---------|---------|-----------|
| **主力(机构)** | 公募基金、私募、险资、国家队、产业资本 | 大(千万~百亿) | 周~年 | 建仓慢、吸筹隐蔽、拉升有节奏、出货周期长 | 超大单+大单净额、龙虎榜机构席位、大宗交易、股东户数变化、筹码分布 |
| **游资(短线热钱)** | 民间敢死队、打板资金、量化短线 | 中(百万~亿) | 1天~2周 | 快进快出、打板接力、造势、隔日砸盘 | 龙虎榜营业部席位、涨停时间与封单、连板晋级、昨日涨停今日表现 |
| **散户** | 个人投资者(包括你爸,哈哈) | 小 | 不定 | 追涨杀跌、情绪化、被主力利用为对手盘 | 小单净额、股东户数、换手率结构 |

**关键认知(框架的诚实边界)**: 我们看到的"大单/中单/小单"是**按成交金额分档**,不是按身份分类。
- 大单 ≠ 主力(量化拆单、游资对倒都会混入大单)
- 小单 ≠ 散户(主力也可以拆小单吸筹)
- **唯一能"实名"识别角色的数据是龙虎榜**——它公布真实买卖营业部,机构席位直接标注"机构专用"。
- 所以我们的框架是:**分档资金流提供"近似方向",龙虎榜/席位数据提供"实锤确认"**。两者结合,单看任一都有陷阱。

## 二、总体分析逻辑:四步法

```
第一步 盘面定调  →  今天盘面在干什么(价格/量/位置/情绪环境)
第二步 分角色拆解 → 主力、游资、散户各自做了什么
第三步 关系与逻辑 → 角色行为 × 盘面关系 → 资金阶段判断 + 涨跌归因
第四步 决策与证伪 → 条件式结论(如果X则Y)+ 证伪信号 + 风险清单
```

每一步都必须可回答、可检查、可推翻。下面逐步展开。

---

## 三、第一步:盘面定调

**目的**: 在分析任何资金之前,先客观描述"价格和成交量在做什么"。这是后续所有解读的坐标系。

### 3.1 看什么

| 维度 | 数据 | 解读要点 |
|------|------|---------|
| 价格行为 | 今日涨跌幅、开盘位置(高开/低开/平开)、盘中形态(冲高回落/低开高走/横盘) | 形态本身是资金意愿的"结果" |
| 量能 | 成交额、换手率、量比、内外盘比 | 量比>1放量,<1缩量;内盘>外盘=主动卖压强 |
| 位置 | 现价 vs MA5/10/20、BOLL 上中下轨 | 位置决定"拉升空间"和"套牢盘压力" |
| 情绪环境 | 全市场热度、上涨占比、赚钱效应、涨停梯队 | 大盘背景决定个股行为含义(大跌日抗跌 ≠ 大涨日强势) |

### 3.2 输出

一段客观描述,例如: *"低开0.5%后震荡上行,午盘收+1.79%,量比0.92缩量,现价站上MA5/10/20,全市场偏暖(热度48)。"*

**注意**: 这一步只陈述事实,不下判断。判断在第三步。

## 四、第二步:分角色拆解

**目的**: 用数据回答"主力/游资/散户各自做了什么"。每个角色有固定的指标组合,缺什么数据就明说缺。

### 4.1 主力(机构)怎么看

**指标组合**:

| 指标 | 数据源 | 解读规则 |
|------|--------|---------|
| 超大单+大单净额(多日) | Tushare moneyflow / 雪球 capital_history | 持续净流入=建仓;持续净流出=出货;一日流入一日流出=分歧 |
| 资金强度 = 主力净额 ÷ 成交额 | moneyflow 计算 | 强度>10% 为显著;同样净额,成交额小的股票更有"主导力" |
| 融资余额变化 | Tushare margin_detail / 雪球 margin | 融资余额=杠杆资金。余额上升+价格滞涨=杠杆盘接盘(风险);余额下降+价格企稳=去杠杆尾声 |
| 股东户数趋势 | Tushare stk_holdernumber | **户数减少=筹码集中=主力吸筹**;户数增加=筹码分散=派发迹象(慢变量,按季) |
| 筹码分布 | Tushare cyq_perf/cyq_chips | 获利盘比例、加权平均成本:现价高于平均成本越多,上方抛压越大 |
| 龙虎榜机构席位 | Tushare top_inst / akshare 龙虎榜 | "机构专用"出现在买方=机构买入实锤;卖方=机构出货实锤 |
| 大宗交易 | 雪球 blocktrans / Tushare block_trade | 大宗折价率:大幅折价=急于出货;溢价=抢筹。买卖营业部可实名识别 |
| 机构调研 | Tushare stk_surv | 调研密集=机构关注度上升(前瞻信号,弱证据) |

**常见陷阱**:
- 单日大单净流入 ≠ 主力建仓(可能是对倒、可能是游资一日游)→ 必须看 3/5 日连续性
- 主力出货可以持续数周,单日"大单流出"只是其中一天

### 4.2 游资怎么看

**指标组合**:

| 指标 | 数据源 | 解读规则 |
|------|--------|---------|
| 龙虎榜上榜 | Tushare top_list | 上榜**原因**直接标注当日异动性质:涨幅偏离值7%(强势)/连续三日偏离20%(连涨)/换手率异常(接力)/振幅异常(分歧) |
| 席位构成 | Tushare top_inst | 买方前5:机构专用多=机构行情;营业部多=游资行情;买一集中度越高,越像单一游资控盘 |
| 营业部实名识别 | Tushare hm_list + top_inst 交叉 | hm_list 提供知名游资(赵老哥、炒股养家、章盟主等)关联营业部名单;匹配到=该游资参与 |
| 涨停时间与封单 | levistock stock_zt_pool_em(盘中)/ Tushare kpl_list(盘后) | 首封越早(9:30-10:00)=资金意愿越强;封单额/流通市值越大=越难被砸开;开板次数多=分歧大 |
| 连板与晋级 | kpl_list status / levistock get_zttt / market_emotion_cls 涨停梯队 | N连板=资金接力;晋级率反映游资市场整体意愿 |
| 昨日涨停今日表现 | levistock stock_yesterday_zt_em | 涨停次日高开回落=一日游(游资出货);次日续涨=资金认可 |
| 炸板(破板) | Tushare kpl_list tag=炸板 / get_pmsl | 涨停被砸开=封板资金撤退,情绪转弱信号 |

**注意**: 龙虎榜是**盘后**数据(17:30后),午间报告只能用到"上一交易日"的龙虎榜。这是数据时效的现实,报告必须标注数据日期,不得假装是今日数据。

### 4.3 散户怎么看

**指标组合**:

| 指标 | 数据源 | 解读规则 |
|------|--------|---------|
| 小单净额(多日) | moneyflow / capital_assort | 散户持续净买入而价格滞涨=散户接盘(危险信号);散户割肉而价格企稳=筹码转移 |
| 股东户数 | stk_holdernumber | 户数暴增=散户涌入(通常是阶段顶部特征);户数大减=筹码集中 |
| 换手率结构 | 行情数据 | 高换手+小单多=散户主导博弈,行情持续性差 |

**解读核心逻辑**: 散户在博弈中通常是被收割方。**"散户接盘"是出货阶段的确认信号**,"散户割肉"是吸筹阶段的辅助信号。

## 五、第三步:关系与逻辑——资金阶段判断模型

**这是整个框架的核武器**: 把"跟着主力走"翻译成可证伪的阶段判断。

### 5.1 四阶段模型

主力的操作周期可划分为四个阶段,每个阶段有明确的证据组合和证伪条件:

| 阶段 | 特征(需多条件同时满足) | 支持证据 | 证伪条件(出现即推翻) |
|------|------------------------|---------|---------------------|
| **吸筹** | 价格横盘/阴跌,主力资金却在流入 | 3-5日超大单+大单净流入、量缩价平、股东户数下降、融资余额平稳 | 大单转为持续净流出 |
| **洗盘** | 拉升途中回调,缩量,大单不流出 | 回调缩量、大单净额基本持平、价格不破关键均线 | 回调放量+大单持续流出(那其实是出货) |
| **拉升** | 放量上涨,主力资金大幅净流入 | 大单净流入+量比>1.5+板块配合+可能上龙虎榜(买方机构/游资席位) | 放量滞涨(量增价不增=对倒出货嫌疑) |
| **出货** | 价格滞涨/冲高回落,主力资金流出 | 大单持续净流出、散户(小单)接盘、股东户数上升、融资余额高位、大宗折价、龙虎榜卖方机构席位 | 大单重新转净流入(那可能是第二波) |

**证据强度规则**:
- 单指标 = 弱证据,只能写"迹象",不能下结论
- 价格+量+资金 三指标共振 = 强证据,可以下阶段判断
- 阶段判断必须写明"证伪条件",方便次日报告验证/推翻

### 5.2 涨跌归因框架

回答"今天为什么涨/跌"——这是爸爸决策的第二核心。归因拆成四因子:

```
今日涨跌 = 板块β(大盘/板块带动) + 个股α(自身事件) + 资金性质(谁在买/卖) + 情绪环境(市场整体)
```

| 因子 | 判断依据 | 数据 |
|------|---------|------|
| 板块β | 个股 vs 所属板块涨跌幅对比;板块在涨而个股跌=个股弱 | 板块排名、板块涨跌幅基准 |
| 个股α | 公告/快讯/事件:业绩、增减持、合同、政策 | 补充信息、快讯、文章 |
| 资金性质 | 谁在买谁在卖(第二节)、净流入流出 | 资金流数据 |
| 情绪环境 | 大盘涨跌、市场热度、上涨占比 | 全市场情绪 |

**输出**: 给每只股票一句话归因,标注证据强度,例如:
*"上涨主因:商业零售板块政策驱动(+2.27%,板块β)+ 业绩快报超预期(个股α);资金面仅小单净流入、主力未大举进场(资金性质:弱)→ 判断为'板块+消息驱动,主力尚未确认'。"*

## 六、第四步:决策与证伪

### 6.1 决策输出的形态

**给爸爸的决策必须是可以执行的条件式结论**,不是涨跌预测:

- ✅ 正确形态: *"主力处于吸筹阶段(证据:5日大单净流入+户数下降),当前缩量横盘。若放量突破MA20并伴随大单净流入,可视为拉升启动信号,考虑买入;若大单转为连续净流出,则吸筹判断失效,观望。"*
- ❌ 错误形态: *"该股资金面良好,有望继续上涨。"* (无条件、无证伪、无操作含义)

### 6.2 决策的三档输出

| 档位 | 适用条件 | 输出内容 |
|------|---------|---------|
| 强判断 | 价格+量+资金三指标共振,证据完整 | 明确的阶段结论 + 操作建议 + 证伪信号 |
| 弱判断 | 部分指标支持,证据不完整 | "迹象"表述 + 需要补看的数据 + 观察条件 |
| 不判断 | 数据缺失或矛盾 | 明说"无法判断",列出缺什么数据 |

### 6.3 风险清单(每次报告必查)

- 解禁(share_float): 近期有无大额解禁,解禁前资金常提前离场
- 减持(stk_holdertrade 已接入): 大股东/高管减持公告
- 质押(pledge_stat): 质押比例过高=大股东资金链风险
- 融资盘(margin_detail 已接入): 融资余额高位+价格滞涨=杠杆踩踏风险
- 炸板/连板失败(游资股): 情绪退潮风险
- 高位置(技术面): 远离均线=获利盘抛压

## 八、分析的可证伪性:写作规范

这是本文档与"普通股评"的根本区别。任何分析段落必须满足:

1. **结论可溯源**: 每个判断后面跟着它依赖的数据(如"3-5日大单净流入:7/28 +1.2亿, 7/29 +0.8亿, 7/30 +1.5亿")。
2. **强弱分层**: 区分"实锤"(龙虎榜席位、公告)、"强证据"(多指标共振)、"弱迹象"(单指标)。
3. **证伪先行**: 阶段判断必须附"什么数据出现,此判断失效"。
4. **时效标注**: 每个数据块标注日期(今日午间/昨日/T-2),严禁把昨日数据冒充今日。
5. **数据缺失坦白**: 缺哪个角色数据就说缺,并说明因此哪些问题无法回答。
6. **禁止**: 无证据断言("资金面良好")、模糊时间词("近期有望")、无条件的买卖建议。

## 十、名词速查表(给投资小白)

| 术语 | 含义 |
|------|------|
| 主力 | 市场上的大资金玩家(机构为主),有能力影响股价走势 |
| 游资 | 短线热钱,快进快出,以打板、接力为典型手法 |
| 龙虎榜 | 交易所每日公布的异动股买卖前5席位名单(涨跌幅偏离7%、换手率异常、振幅异常、连板等会上榜) |
| 席位/营业部 | 龙虎榜上显示的券商营业部名称,是资金的"身份证"("机构专用"=机构) |
| 封单 | 涨停价上挂的买单金额,封单越大越难开板 |
| 炸板/破板 | 涨停后被大卖单砸开 |
| 连板 | 连续涨停(2板=2连板),代表资金接力意愿 |
| 首封时间 | 当天第一次封上涨停的时间,越早越强 |
| 吸筹/洗盘/拉升/出货 | 主力操作的四个典型阶段 |
| 量比 | 今日每分钟均量 ÷ 过去5日每分钟均量,>1放量 <1缩量 |
| 内外盘 | 外盘=主动买成交量,内盘=主动卖成交量;外盘>内盘=买盘主动 |
| 筹码分布 | 不同价位上持仓量的分布,可看获利盘和套牢盘 |
| 融资余额 | 投资者借钱(融资)买入后尚未偿还的金额,是杠杆资金温度计 |
| 股东户数 | 持有该股的账户总数;户数减少=人均持股增加=筹码集中 |
| 大宗交易 | 单笔大额成交(一般>30万股或200万),盘后约定价格成交,可看折溢价 |
| 折价率 | 大宗成交价相对收盘价的折让,大幅折价=卖方急于出手 |
| 资金强度 | 主力净流入 ÷ 当日成交额,衡量资金主导力 |
| 获利盘 | 现价以下买入的持仓比例,获利盘多=抛压大 |
| 机构调研 | 上市公司接待机构投资者调研,调研多=机构关注 |
| 委托队列/L2 | 显示逐笔委托挂单的付费数据,免费数据无法获取 |
| 北向资金 | 境外资金通过沪深港通买入A股;日频数据2024年8月20日起停发 |
