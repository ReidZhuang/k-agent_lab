## 一、实体关系图

```
股票/ETF (code)
    ├── 实时行情 → GET http://hq.sinajs.cn/list={prefix+code}
    │   ├── A股 → 47 字段（含买卖盘口五档）
    │   ├── ETF → 47 字段（同上格式）
    │   └── 港股 → 18 字段（含 PE/市值/周息率）
    │
    ├── K线数据 → GET /CN_MarketData.getKLineData?symbol={prefix+code}&scale={n}
    │   ├── 5分钟  → scale=5
    │   ├── 15分钟 → scale=15
    │   ├── 30分钟 → scale=30
    │   ├── 60分钟 → scale=60
    │   └── 日线   → scale=240
    │
    ├── 利润表 → GET /vFD_ProfitStatement/stockid/{code}/...
    │   ├── 营业总收入 / 营业总成本
    │   ├── 营业利润 / 利润总额 / 净利润
    │   ├── 归母净利 / 少数股东损益
    │   └── 基本每股收益 / 稀释每股收益
    │
    ├── 资产负债表 → GET /vFD_BalanceSheet/stockid/{code}/...
    │   ├── 流动资产 / 非流动资产 = 资产总计
    │   ├── 流动负债 / 非流动负债 = 负债合计
    │   └── 所有者权益
    │
    └── 现金流量表 → GET /vFD_CashFlow/stockid/{code}/...
        ├── 经营活动现金流净额
        ├── 投资活动现金流净额
        └── 筹资活动现金流净额
```

### 代码前缀规则

```
6xxxxx → sh (上海)
0xxxxx → sz (深圳)
3xxxxx → sz (深圳/创业板)
8xxxxx → bj (北交所)
hkxxxx → hk (港股，保留前缀)
```

## 二、查询路径索引

按自然语言问题 → 对应的新浪数据路径。

### 2.1 实时行情类

| 问题 | 调用路径 |
|------|---------|
| "宁德时代今天股价多少" | `fetch_quotes(['300750'])` → `price` |
| "茅台涨了还是跌了" | `fetch_quotes(['600519'])` → `price` 与 `prev_close` 比较 |
| "宁德时代开盘价多少" | `fetch_quotes(['300750'])` → `open` |
| "今天大盘成交额" | `fetch_quotes(['000001'])` → `amount`（上证综指） |
| "腾讯今天港股多少" | `fetch_quotes(['hk00700'])` → 港股解析模式 |
| "科创50ETF行情" | `fetch_quotes(['sh588000'])` → ETF 格式 |
| "宁德时代买卖盘口" | `fetch_quotes(['300750'])` → 买五/卖五字段 |
| "宁德时代成交额" | `fetch_quotes(['300750'])` → `amount` |

### 2.2 K线数据类

| 问题 | 调用路径 |
|------|---------|
| "宁德时代最近20天日K" | K线接口: `symbol=sz300750, scale=240, datalen=20` |
| "宁德时代60分钟K线" | K线接口: `symbol=sz300750, scale=60, datalen=24` |
| "今天5分钟K线走势" | K线接口: `symbol=sz300750, scale=5, datalen=50` |
| "最近一周走势" | K线接口: `scale=240, datalen=5`（回退到日线） |

### 2.3 财务数据类

| 问题 | 调用路径 |
|------|---------|
| "宁德时代最新营收" | 利润表 → 找到"营业总收入"行 |
| "宁德时代毛利率" | 利润表 → (营业收入 - 营业成本) / 营业收入 |
| "宁德时代净利率" | 利润表 → 净利润 / 营业总收入 |
| "宁德时代研发费用" | 利润表 → 找到"研发费用"行 |
| "宁德时代每股收益" | 利润表 → 找到"基本每股收益(元/股)"行 |
| "宁德时代货币资金" | 资产负债表 → 找到"货币资金"行 |
| "宁德时代资产负债率" | 资产负债表 → 负债合计 / 资产总计 |
| "宁德时代存货" | 资产负债表 → 找到"存货"行 |
| "宁德时代固定资产" | 资产负债表 → 找到"固定资产"行 |
| "宁德时代经营现金流" | 现金流量表 → "经营活动产生的现金流量净额"行 |
| "宁德时代自由现金流" | 现金流量表 → 经营现金流净额 - 购建固定资产支付的现金 |
| "宁德时代现金余额" | 现金流量表 → "期末现金及现金等价物余额"行 |

## 三、数据源优先级矩阵

### 3.1 新浪 vs 其他数据源

| 查询类型 | 新浪数据可用性 | 第一选择 | 替代方案 |
|---------|:-------------:|:--------:|:--------:|
| 实时股价/涨跌幅 | ✅ | 新浪实时行情 | 腾讯（无延迟） |
| 买卖盘口（五档） | ✅ 唯一来源 | 新浪实时行情 | ❌ 无替代 |
| 港股行情（PE/市值） | ✅ | 新浪港股行情 | 腾讯财经 |
| 分时K线 | ✅ | 新浪K线接口 | ❌ 无替代 |
| 日K线 | ✅ | 新浪K线接口 | 腾讯/东方财富 |
| 利润表（详细科目） | ✅ | 新浪HTML解析 | akshare / 东方财富 |
| 资产负债表（详细科目） | ✅ | 新浪HTML解析 | akshare / 东方财富 |
| 现金流量表（详细科目） | ✅ | 新浪HTML解析 | akshare / 东方财富 |
| 估值（PE/PB/市值-A股） | ❌ 无此数据 | 腾讯财经 | akshare |
| 资金流向 | ❌ 无此数据 | akshare | — |
| 行业板块分类 | ❌ 无此数据 | akshare | — |
| 财务摘要关键指标 | ❌ 页面结构乱 | akshare / 东方财富 | — |

### 3.2 按场景选择数据源

| 场景 | 推荐数据源 | 原因 |
|------|:----------:|------|
| 快速查股价 | 新浪 or 腾讯 | 速度最快 |
| 查PE/PB/市值 | **腾讯财经** | 新浪没有，腾讯有 |
| 查详细报表科目 | **新浪** | 三大报表逐行解析，其它源只有摘要 |
| 查多期财务趋势 | **akshare**(80指标×40期) | 新浪只有5期，akshare覆盖10年 |
| 查资金流向 | **akshare** | 新浪不支持 |
| 查板块行情 | **akshare** | 新浪不支持 |

## 四、新浪独有优势

以下数据只有新浪能免费提供，其他源没有：

1. **五档买卖盘口**: 买一~买五 + 卖一~卖五，共10档价格/数量
2. **详细三大报表**: 利润表30行、资产负债表96行、现金流量表78行，其他源只提供摘要
3. **港股行情含估值**: 港股市盈率、总市值、周息率
4. **分时K线**: 5分/15分/30分/60分
