# 新浪财经数据接口手册

> 说明: 本文档只记录**免费、无须登录**即可通过 HTTP 直连获取的新浪财经数据。
> 所有接口通过 requests 调用，无需 SDK 或 API Key。

---

## 一、实时行情（hq.sinajs.cn）

### 1.1 A 股/ETF 实时行情

**接口**: `GET http://hq.sinajs.cn/list={codes}`

**参数**:
- `codes`: 逗号分隔的股票代码，上海 `sh` + 代码，深圳 `sz` + 代码
- 需要 `Referer: https://finance.sina.com.cn` 请求头

**示例**:
```
http://hq.sinajs.cn/list=sh600519,sz300750,sz002594
```

**返回格式**（47 个 ~ 分隔字段）:
```
var hq_str_sh600519="XD贵州茅,1199.000,1184.080,1174.030,1199.000,1173.300,1174.010,1174.280,4414987,5229209724.000,...2026-06-26,14:41:08,00";
```

| 序号 | 字段 | 含义 |
|:----:|------|------|
| 0 | 股票名称 | - |
| 1 | 今日开盘价 | - |
| 2 | 昨日收盘价 | - |
| 3 | 当前价格 | - |
| 4 | 今日最高价 | - |
| 5 | 今日最低价 | - |
| 6 | 买一价 | - |
| 7 | 卖一价 | - |
| 8 | 成交股数 | - |
| 9 | 成交金额(元) | - |
| 10-19 | 买五~买一 | 各档价格+数量 |
| 20-29 | 卖一~卖五 | 各档价格+数量 |
| 30 | 日期 | - |
| 31 | 时间 | - |

**数据延迟**: 约 15 分钟（免费版）

**已实现**: `web_search_base/sources/sina.py` 中的 `fetch_quotes()` 和 `format_quote()`

## 二、K 线数据

**接口**: 
```
GET http://money.finance.sina.com.cn/quotes_service/api/jsonp_v2.php/var=/CN_MarketData.getKLineData?symbol={code}&scale={scale}&ma=no&datalen={count}
```

**参数**:

| 参数 | 含义 | 可选值 |
|------|------|--------|
| symbol | 深圳加 `sz`，上海加 `sh` + 代码 | `sz300750`, `sh600519` |
| scale | 时间粒度 | 5(5分), 15(15分), 30(30分), 60(60分), 240(日) |
| ma | 移动均线 | `no` |
| datalen | 返回条数 | 最多约 1000 条 |

**示例**:
```
# 30分钟K线最近5条
http://money.finance.sina.com.cn/quotes_service/api/jsonp_v2.php/var=/CN_MarketData.getKLineData?symbol=sz300750&scale=30&ma=no&datalen=5

# 日线最近20条
http://money.finance.sina.com.cn/quotes_service/api/jsonp_v2.php/var=/CN_MarketData.getKLineData?symbol=sz300750&scale=240&ma=no&datalen=20
```

**返回格式**（JSONP）:
```json
var=([
  {"day":"2026-06-26 14:30:00","open":"382.850","high":"382.980","low":"382.370","close":"382.380","volume":"763000"},
  {"day":"2026-06-26 14:35:00","open":"381.880","high":"382.930","low":"381.880","close":"381.880","volume":"1031020"}
]);
```

**每个数据点字段**:
- `day`: 日期时间（日线只显示日期）
- `open`: 开盘价
- `high`: 最高价
- `low`: 最低价
- `close`: 收盘价
- `volume`: 成交量（股数）

**支持的时间粒度**:
- ❌ scale=1（1分钟）— 不支持
- ✅ scale=5（5分钟）
- ✅ scale=15（15分钟）
- ✅ scale=30（30分钟）
- ✅ scale=60（60分钟）
- ✅ scale=240（日线）
- ❌ scale=720（周线）— 不支持
- ❌ scale=1440（月线）— 不支持

**数据延迟**: 分时数据接近实时；日线数据除息除权后调整

## 三、三大财务报表（HTML 解析）

注: 新浪的财务数据通过 HTML 表格发布，需要解析 HTML。每个表格包含最近 **5 个报告期**（当前年度的各季报 + 上年度）。

### 3.1 利润表

**接口**: 
```
GET https://vip.stock.finance.sina.com.cn/corp/go.php/vFD_ProfitStatement/stockid/{code}/ctrl/part/displaytype/4.phtml
```

**返回**: 约 30 个科目 × 5 个报告期的 HTML 表格

**主要科目**:
```
一、营业总收入
  营业收入
二、营业总成本
  营业成本
  营业税金及附加
  销售费用
  管理费用
  财务费用
  研发费用
  资产减值损失
公允价值变动收益
投资收益
三、营业利润
加: 营业外收入
减: 营业外支出
四、利润总额
减: 所得税费用
五、净利润
  归属于母公司所有者的净利润
  少数股东损益
六、每股收益
  基本每股收益(元/股)
  稀释每股收益(元/股)
七、其他综合收益
```

**单位**: 万元

### 3.2 资产负债表

**接口**: 
```
GET https://vip.stock.finance.sina.com.cn/corp/go.php/vFD_BalanceSheet/stockid/{code}/ctrl/part/displaytype/4.phtml
```

**返回**: 约 96 个科目 × 5 个报告期

**主要科目结构**:
```
流动资产
  货币资金
  交易性金融资产
  应收票据及应收账款
  存货
  其他流动资产
  流动资产合计
非流动资产
  固定资产
  在建工程
  无形资产
  商誉
  非流动资产合计
资产总计
流动负债
  短期借款
  应付票据及应付账款
  流动负债合计
非流动负债
非流动负债合计
负债合计
所有者权益
  实收资本(股本)
  资本公积
  未分配利润
负债和所有者权益总计
```

### 3.3 现金流量表

**接口**: 
```
GET https://vip.stock.finance.sina.com.cn/corp/go.php/vFD_CashFlow/stockid/{code}/ctrl/part/displaytype/4.phtml
```

**返回**: 约 78 个科目 × 5 个报告期

**主要科目结构**:
```
一、经营活动产生的现金流量
  销售商品、提供劳务收到的现金
  经营活动现金流入小计
  购买商品、接受劳务支付的现金
  经营活动现金流出小计
  经营活动产生的现金流量净额
二、投资活动产生的现金流量
  投资活动现金流入/流出小计
  投资活动产生的现金流量净额
三、筹资活动产生的现金流量
  筹资活动现金流入/流出小计
  筹资活动产生的现金流量净额
四、汇率变动对现金及现金等价物的影响
五、现金及现金等价物净增加额
六、期末现金及现金等价物余额
```

### 3.4 财务摘要（关键指标）

**接口**:
```
GET https://vip.stock.finance.sina.com.cn/corp/go.php/vFD_FinanceSummary/stockid/{code}.phtml
```

**返回**: HTML 页面含多个表格，包含关键财务指标如营收、净利、每股收益等。

**注意**: 该页面侧边栏与数据表格混在同一个 HTML 中，解析时需要定位到包含 "报表日期" 的表格。

## 六、与 web_search_base 的集成

### 当前现状
已在 `web_search_base/sources/sina.py` 中: `fetch_quotes()` + `format_quote()`
- 支持 A 股实时行情、涨跌幅
- 无估值数据（PE/PB/市值 — 这些在腾讯财经中有）

### 待扩展
1. K 线数据: 新增 `fetch_kline(code, scale, count)` 函数
2. 利润表: 新增 `fetch_profit_statement(code)` + HTML 解析
3. 资产负债表: 新增 `fetch_balance_sheet(code)` + HTML 解析
4. 现金流量表: 新增 `fetch_cash_flow(code)` + HTML 解析
5. 港股行情: 在 `fetch_quotes()` 中增加 `hk` 前缀支持

### 局限（新浪没有的数据）
- ❌ 实时估值（PE/PB/市值）
- ❌ 市值数据
- ❌ 资金流向
- ❌ 龙虎榜（已下线）
- ❌ 行业板块分类
