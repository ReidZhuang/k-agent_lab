## 四、腾讯独有优势

以下数据只有腾讯财经能免费直接获取（无需Token、无需登录）：

1. **总市值 + 流通市值** — 雪球需Token，新浪无
2. **市盈率(动态)** — 雪球需Token，新浪无
3. **市净率** — 雪球需Token，新浪无
4. **量比** — 其他源均无
5. **涨跌停价** — 其他源需Token或无

### 一句话定位

**腾讯 = 实时行情 + 估值数据的免费快照源**

与新浪互补（新浪有盘口但无估值），与雪球各有优劣（雪球有Token时可代替）。
