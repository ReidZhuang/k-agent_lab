# 腾讯财经数据接口参考手册

> 接口: `https://web.sqt.gtimg.cn/q={code}`
> 特点: 免费、无需 Token、近实时、含估值数据（PE/PB/市值）
> 响应: 88 个 `~` 分隔字段，~0.1-0.3s

---

## 一、接口规范

### 端点

```
GET https://web.sqt.gtimg.cn/q={codes}
```

### 参数

- `codes`: 逗号分隔的股票代码（需加前缀 `sh`/`sz`）
- 示例: `https://web.sqt.gtimg.cn/q=sz300750,sh600519`

### 代码前缀

```python
if code.startswith('6'):      prefix = 'sh'
elif code.startswith(('0','3','8')): prefix = 'sz'
```

## 三、已实现功能

`web_search_base/sources/tencent.py`:

| 函数 | 说明 |
|------|------|
| `fetch_quotes(codes)` | 批量获取多只股票的行情+估值数据 |
| `format_quote(code, name)` | 格式化为可读文本（含涨跌幅/市值/PE/PB） |

### 调用示例

```python
from sources.tencent import fetch_quotes, format_quote

# 批量获取
quotes = fetch_quotes(['300750', '002594'])
print(quotes['300750']['pe_dynamic'])  # → 22.32
print(quotes['300750']['market_cap_total'])  # → 16219.22

# 格式化
print(format_quote('300750', '宁德时代'))
```

### 输出格式

```
宁德时代(300750) 实时行情与估值

  最高/最低: 409.81 / 381.00

  市盈率(动): 22.32
  市净率: 5.39
  换手率: 1.09%

(来源: 腾讯财经)
```

## 四、数据特点

- **实时性**: 接近实时（无 15 分钟延迟），优于新浪
- **估值数据**: 总市值/流通市值/PE/PB/换手率/量比 — 新浪没有这些
- **无需 Token**: 纯 HTTP GET，无任何认证
- **速度**: ~0.1-0.3s，非常快
- **局限**: 无买卖盘口（新浪有）、无K线、无财务数据
