腾讯财经该接口返回的是**纯文本格式**数据，**非标准JSON/XML**，需要按固定字段顺序解析。

### 📡 接口基础信息

| 项目 | 说明 |
|------|------|
| **接口地址** | `http://qt.gtimg.cn/q={code}` 或 `https://web.sqt.gtimg.cn/q={code}` |
| **请求方式** | GET |
| **编码格式** | **GBK**（请求后需指定 `encoding='gbk'`，否则中文会乱码） |
| **多股查询** | 用逗号分隔多个代码，如 `q=sh600000,sz000001` |
| **返回格式** | `v_代码="字段1~字段2~...~字段N";` |

### 🌐 不同市场的字段差异

| 市场 | 代码前缀 | 字段数量 | 说明 |
|------|---------|---------|------|
| **沪市A股** | `sh` | 约60+字段 | 字段最全，包含五档盘口 |
| **深市A股** | `sz` | 约60+字段 | 与沪市基本一致 |
| **港股** | `hk` | 字段较少 | 部分A股特有字段不适用 |
| **美股** | `us` | 字段较少 | 部分A股特有字段不适用 |
| **简明数据** | `s_` 前缀 | 约10个字段 | 仅包含核心行情，如 `q=s_sh600519` |

### ⚠️ 注意事项

1. **无官方文档**：该接口为腾讯财经网页内部使用，没有公开发布的API文档，字段释义来自开发者社区逆向工程。
2. **编码必须为GBK**：否则中文名称会乱码。
3. **控制请求频率**：避免高频请求导致IP被临时封禁。
4. **字段可能变动**：该接口并非公开API，腾讯可能随时调整字段顺序或内容，建议在实际使用前用测试代码验证。
