# 各数据源输出格式示例

---

## 一、东方财富数据中心（财务主表）

**调用**: `eastmoney.format_financial_report("300750", "宁德时代")`

**字段数**: 165 个（选择关键字段展示）

**输出示例**:
```
宁德时代(300750) 财务数据报告
========================================

── 2026一季报 ──
营业收入: 1291.3亿 (同比52.4%)
营业利润: 320.4亿
净利润: 207.4亿 (同比48.5%)
扣非净利润: 180.9亿
毛利率: 24.82%
净利率: 17.61%
每股收益: 4.58
ROE: 5.98%
总资产: 10463.3亿
净资产: 3942.3亿
资产负债率: 62.32%

── 2025年报 ──
营业收入: 4237.0亿 (同比17.0%)
净利润: 722.0亿 (同比42.3%)
...

(数据来源: 东方财富数据中心, 2026-06-25 23:38)
```

**特点**:
- 仅最近 4 个报告期
- 专注核心财务指标（营收、净利、毛利率、ROE、负债率）
- 附同比增长率
- 响应快（~0.3s）

## 二、Akshare 财务摘要

**调用**: `akshare_em.format_abstract("300750", "宁德时代")`

**80 个指标 × 30+ 报告期**

**输出示例**:
```
宁德时代(300750) 财务摘要
========================================

归母净利润:
  20260331: 20737710000.0
  20251231: 72201282000.0
  20250930: 49034109000.0
  20250630: 30485139000.0

毛利率:
  20260331: 24.8156219851
  20251231: 26.2728475704
  ...
```

**覆盖指标分类**:
| 类别 | 指标数 | 示例 |
|------|:------:|------|
| 常用指标 | 17 | 营收、净利、扣非、ROE、毛利率 |
| 每股指标 | 15 | 每股收益、每股净资产、每股现金流 |
| 盈利能力 | 15 | ROE(摊薄/平均/扣非)、ROA、净利率 |
| 成长能力 | 4 | 营收增长率、净利增长率 |
| 收益质量 | 7 | 经营现金流/营收、期间费用率 |
| 财务风险 | 6 | 流动比率、速动比率、资产负债率 |
| 营运能力 | 9 | 存货周转率、总资产周转率 |

**响应时间**: ~0.3s

  市净率: 5.49
  换手率: 0.68%
  成交额: 11427908617.5

**响应时间**: ~0.1-0.3s

## 四、新浪财经（实时行情）

**调用**: `sina.format_quote("300750", "宁德时代")`

**输出示例**:
```
宁德时代(300750) 实时行情
  当前价: 384.72
  涨跌幅: -17.18 (-4.27%)
  最高/最低: 409.81 / 384.50
  开盘/昨收: 401.00 / 401.90
  成交额: 11427908617.5
```

**差异**: 新浪不含估值数据（市盈率、市净率），无总市值信息

## 五、搜索路由自动选择逻辑

| 查询关键词 | 路由目标 | 数据特点 |
|-----------|---------|---------|
| 公司名（无额外关键词） | 东方财富财报 | 最新 4 期核心数据 |
| 对比/比较 + 两家公司 | 东方财富对比表 | 含合并对比表 |
| 股价/行情/市值/市盈率 | 腾讯财经 | 实时价+估值 |
| 趋势/历史/增长率 | akshare 摘要 | 多期趋势 |
| 全面/深入/详细 | 东方财富 + akshare | 财报+摘要双重 |
