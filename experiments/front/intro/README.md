# 股神的秘密 — 前端

股神的秘密是一个面向老年用户的 A 股股票跟踪与报告生成系统。用户可通过 Tailscale 透传从个人 PC 连接部署在 Linux 服务器上的服务。

## 核心功能

- **登录认证** — 用户名密码登录，账号在数据库中预配置
- **个人文件空间** — 树状文件管理器，管理 `.md` 报告文档
- **股票池** — 跟踪自选股票，展示昨日行情数据（Tushare）
- **文档预览** — 在线预览 Markdown 文档（VS Code 风格渲染）
- **文档下载** — MD 文档一键转换为 Word (.docx) 格式下载
- **收藏夹** — 收藏常用文档，快速访问

## 设计原则

- **大字适老** — 全站基础字号 18px，按钮/输入框 48px 高，触控友好
- **原木风格** — 暖木色 `#C4A882` 为主色调，米白底色，柔和护眼
- **移动适配** — 支持手机浏览器访问，侧栏可折叠为抽屉
- **简约商务** — 大面积留白，圆角柔和，信息层级清晰
