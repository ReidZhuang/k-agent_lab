# 用户使用手册

## 一、登录

在浏览器打开系统地址（如 `http://localhost:8320` 或 Tailscale IP），进入登录页面：

1. 输入**用户名**
2. 输入**密码**
3. 点击 **"登录"** 按钮

![登录页示意]
（说明：登录卡片居中，暖木色渐变图标 + 原木色输入框）

> 登录失败会提示"用户名或密码错误"。
> 连续 24 小时不操作需要重新登录。

### 左侧 — 个人空间

- **🔍 搜索栏** — 输入股票名称，快速定位相关文件夹
- **⭐ 收藏夹** — 收藏的文档列表，点击可直接打开。点击标题栏可折叠/展开
- **📁 文件树** — 目录和文件的树状列表，展开文件夹查看内容
- 每个文件前的 **小方框** 用于多选，可批量操作
- 文件右侧的 **☆/★** 按钮用于收藏/取消收藏
- 底部 **"⬇ 下载选中文档"** 按钮，下载选中文件（单文件→docx，多文件→zip）

### 右侧 — 主内容区

通过顶部标签页切换：

| 标签页 | 功能 |
|--------|------|
| 📈 **股票池** | 搜索股票、管理自选池、查看昨日行情 |
| 📄 **文档** | 预览选中的 Markdown 文档 |

## 三、股票池功能

### 3.1 搜索股票

1. 在输入框中输入股票名称或代码（支持中英文逗号分隔多只）
2. 点击 **"🔍 查询"** 按钮
3. 匹配结果会显示在下方结果框中

### 3.2 加入股票池

1. 查询确认股票信息无误后
2. 点击 **"✓ 确认加入股票池"** 按钮
3. 股票自动加入下方"我的股票池"表格

### 3.3 查看行情

股票池表格显示以下数据（来自 Tushare 昨日日终行情）：

| 字段 | 说明 |
|------|------|
| 股票名称 | A 股股票名称 |
| 代码 | TS 代码（如 300750.SZ） |
| 开盘 | 昨日开盘价 |
| 最高 | 昨日最高价 |
| 最低 | 昨日最低价 |
| 昨收 | 昨日收盘价 |
| 涨跌幅 | （收盘 - 昨收）/ 昨收 × 100% |
| 涨跌额 | 收盘 - 昨收 |
| 成交量 | 昨日总成交量（手） |
| 成交额 | 昨日总成交额（千元） |
| 换手率 | 昨日换手率（%） |
| 加入时间 | 加入股票池的时间 |

> 行情数据每个交易日 15:00-16:00 更新。非交易日和开盘期间显示上一个交易日的数据。

### 3.4 移除股票

点击股票行右侧的 **"✕"** 按钮，确认后从股票池移除。

## 四、文档功能

### 4.1 浏览文档

1. 在左侧文件树中点击 `.md` 文件
2. 右侧自动切换到 **📄 文档** 标签页
3. 文档以 Markdown 渲染格式显示（类似 VS Code 预览效果）

支持格式：
- 标题（H1-H4）
- 粗体、斜体
- 有序/无序列表
- 表格
- 代码块（带语法高亮）
- 引用
- 链接

### 4.2 收藏文档

- 点击文件右侧的 **☆** 图标 → 变为 **★**，文件加入收藏夹
- 再次点击 **★** → 取消收藏
- 在 **⭐ 收藏夹** 中点击文档可直接打开

### 4.3 下载 Word 文档

**下载单个文档：**
1. 在文件列表中勾选文件（点击文件前的复选框）
2. 确保只勾选了一个文件
3. 点击底部 **"⬇ 下载选中文档"**
4. 弹出进度浮层，转换完成后自动下载 `.docx` 文件

**批量下载：**
1. 勾选多个文件
2. 点击 **"⬇ 下载选中文档"**
3. 转换为多个 `.docx` 后打包为 `.zip` 下载

> 转换引擎会将 `.md` 格式渲染为 VS Code 风格的 Word 文档，包含标题底线、表格样式、代码高亮等。

## 五、手机端使用

系统支持手机浏览器访问：

1. 在手机浏览器中输入与 PC 相同的地址
2. 界面自动适配手机屏幕
3. 左侧文件树默认隐藏，点击左上角 **☰** 按钮展开
4. 表格支持左右滑动查看全部列

> 建议将网页添加到手机主屏幕，获得类似 App 的体验。

## 六、注意事项

- **非交易日**：股票池的行情数据在非交易日不更新，显示最近一个交易日的数据
- **首次使用**：首次查询股票时，系统会自动从 Tushare 拉取全市场股票列表，可能需要几秒钟
- **文档格式**：只支持 `.md` 和 `.txt` 格式的文件预览和下载
- **网络要求**：展示昨日行情需要服务器能访问 Tushare API（https://api.tushare.pro）
- **数据延迟**：Tushare 日线行情在每个交易日 15:00-16:00 入库，在此之前显示的是上一日数据
