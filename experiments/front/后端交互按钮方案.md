# 股小神回复操作按钮 + 反馈落库方案(2026-08-19)

> 需求: agent 每一条回复完整输出后, 在其下方显示一组操作按钮(复制/保存成文档/重新生成/喜欢/不喜欢),
> 样式仿 DeepSeek 网页版, 作用范围仅限该条回复。反馈用于未来优化 openclaw skills。

## 核实过的事实

- 前端实际数据库 = `/home/stockagent/project_space/database/report_market.db`(backend/config.py:10 DB_PATH)
  - 已有表: chat_session(2)/chat_message(12, 有稳定主键 id)/user(3)/stock_pool/user_favorite
- openclaw 落盘: `~/.openclaw/agents/mx-public/sessions/<uuid>.jsonl`(逐轮 user/assistant/消息) + `.trajectory.jsonl`(skill/工具清单)
  - sessionKey = `agent:mx-public:<user_id>-<conv_id>`, 可从文件内容反查定位 transcript, 保留约 7 天
  - trajectory 可干净提取该会话调用过的 skill/tool(mx-ds-mcp__mx_ashare_finance_data 等), 已实测
- 文件名轻量总结: jieba TextRank(已装入 conda stock_agent, 清华源, 19MB)
  - 无监督、无 LLM、通用(不绑定股票/板块), 已实测多类 query 均能抽出可读主题

## 各按钮实现

| 按钮 | 实现 | 成本 |
|---|---|---|
| 复制 | 纯前端 `navigator.clipboard.writeText(m.content)` + ✅ 反馈 | 低 |
| 保存成文档 | 前端取该条回复的上一条 user message 作 query → 后端 jieba TextRank 生成文件名(2026-08-18_贵州茅台财务数据.md) → 写盘到用户空间 `股小神互动文档/`; 不弹窗直接保存; TextRank 抽不出则 query 截断兜底 | 中低 |
| 重新生成 | 纯前端: 删掉末尾 assistant 回复(内存+DB), 保留用户 query, 重发最后一条 user message → 流式重答。不改 openclaw 内核 | 低 |
| 喜欢/不喜欢 | 前端点亮; 后端写 chat_feedback 表; 解锁交互简单 | 中 |

## 落库设计(按已确认决策)

- 落库位置: report_market.db(与聊天同库)
- 只记录 喜欢/不喜欢(不含 copy/保存/重新生成)
- dislike: 当场抓 skill 快照; like: 只存轻量 id
- 表结构:

```sql
CREATE TABLE IF NOT EXISTS chat_feedback (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id    INTEGER NOT NULL,
    conv_id    TEXT,             -- sessionKey 里的 conv_id, 用于回查 transcript
    message_id INTEGER,          -- chat_message.id
    feedback   TEXT NOT NULL,    -- 'like' / 'dislike'
    skills     TEXT,             -- 仅 dislike: transcript trajectory 抓的 skill 清单 JSON 快照
    created_at TEXT DEFAULT (datetime('now','localtime'))
);
```

## 后端接口(新增)

- `POST /api/chat/feedback` — body: {conv_id, message_id, feedback}
  - dislike 时后端扫描 sessions 目录按 sessionKey 定位 transcript → trajectory 提取 skill 清单 → JSON 存 skills 列
- `POST /api/explorer/write` — 保存文档 {dir, filename, content} → 写 .md 到用户空间
  - 内置 jieba TextRank 生成文件名(也可前端算好传 filename)
