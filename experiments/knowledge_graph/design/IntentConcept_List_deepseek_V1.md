## 一、前置说明

| **🟣 雪球(pysnowball)** | 需Token，行业估值对比/股票→概念反向聚类独有 |
| **⚪ 系统生成(LLM)** | 需求说明书特有业务模块，由LLM生成，无直接API |

### 1.2 IntentConcept 界定原则（重申）

| 原则 | 说明 |
| :--- | :--- |
| **独立分析视角** | 每个概念代表一个用户可独立发起的分析维度，用户问问题时可单独命中 |
| **数据源同质** | 同一概念下的核心字段尽量来自同一类数据源，避免跨源混合导致取数复杂 |
| **业务闭环** | 每个概念能支撑一个完整的"用户判断"场景，而非零散字段的堆砌 |
| **全局价值** | 每个概念独立有用，且能在下游工作流中被组合使用 |
| **边界清晰** | 概念之间不重叠、不嵌套，一个字段只归属一个最贴切的概念 |
