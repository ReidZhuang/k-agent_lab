## API 调用
HTTP GET: https://web.sqt.gtimg.cn/q={code}

- code: sh600519 或 sz300750（sh=上海, sz=深圳）
- 批量: 逗号分隔多个代码
- 请求需带 User-Agent 头
- **必须跟随 302 重定向**（加 allow_redirects=True）

```python
import requests
r = requests.get('https://web.sqt.gtimg.cn/q=sh600519',
                 headers={'User-Agent': 'Mozilla/5.0'},
                 timeout=10, allow_redirects=True)
text = r.text
```

- 免 Token
- 返回 ~ 分隔的纯文本

## 生成步骤
1. 组装请求：URL 中 {code} 替换为查询条件中的代码/名称
2. 发送请求并接收响应
3. 按响应格式解析数据
4. 在字段映射表中找到各目标字段的索引位置
5. 按索引提取字段值
6. 打印结果

## 示例
**示例：取 sz300750 的 price（当前价）和 pct_chg（涨跌幅%）**

```python
import requests

# ── 1. 组装 API URL ──
code = "sz300750"                     # 查询主体：股票代码
url = f"https://web.sqt.gtimg.cn/q={code}"

# ── 2. 发送请求 ──
resp = requests.get(url,
    headers={"User-Agent": "Mozilla/5.0"},
    timeout=10, allow_redirects=True)

# ── 3. 解析返回数据 ──
fields = resp.text.split("~")

# ── 4. 按字段映射表的索引提取目标字段 ──
price = float(fields[3])              # 目标字段: price → 索引 3
pct_chg = float(fields[32])           # 目标字段: pct_chg → 索引 32

# ── 5. 打印结果 ──
print(f"price={price}, pct_chg={pct_chg}%")
```
