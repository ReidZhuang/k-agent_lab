## 生成步骤
1. 【硬编码】import os, tushare as ts，设置 token，初始化 pro 【删除这一条，硬编码代替】
2. 【LLM 填充】调用 pro.daily()，传入：
   - ts_code ← 查询主体.代码
   - start_date, end_date ← 查询范围.时间
3. 从返回的 DataFrame 中按列名提取 查询指标
4. 用 print() 输出，格式 f"{指标名}={值}" 【为什么要打印出来？】

## 代码格式标准
- 变量名: 蛇形
- 空数据: if df.empty: print("无数据"); return
- 打印: print(f"字段名={值}")
- 一次取所有指标，不要一次只取一个

## 示例
查询条件:
  主体: {'代码': '000001.SZ'}
  指标: ['close', 'pct_chg']
  范围: {'时间': '20260701 ~ 20260714'}

```python
# ===== 以下需 LLM 根据查询条件生成 =====
pro = ts.pro_api()    【解释为什么要有这一句】
df = pro.daily(
    ts_code="000001.SZ",               # ← 查询主体.代码
    start_date="20260701",              # ← 查询范围.时间 起始
    end_date="20260714",                # ← 查询范围.时间 结束
)
if df.empty:
    print("无数据")
else:
    row = df.iloc[0]
    close = row["close"]                # ← 查询指标: close → DataFrame 列名
    pct_chg = row["pct_chg"]            # ← 查询指标: pct_chg → DataFrame 列名
    print(f"close={close}, pct_chg={pct_chg}%")
```
