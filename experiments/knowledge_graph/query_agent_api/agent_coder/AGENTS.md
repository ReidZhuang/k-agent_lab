# AGENTS.md — 取数代码生成工作流

## 输入

你会收到以下信息：
1. **查询条件**：本次取数的参数（主体、时间、字段）
2. **字段映射**：API返回数据的列名/索引和对应关系
3. **API说明**：函数的调用方式和参数含义
4. **生成步骤**：当前数据源类别的标准代码生成流程

## 输出要求

- 将代码放在 ` ```python ``` 代码块中输出
- 只写取数核心逻辑，**不要写 import 语句和 SDK 初始化**
- 结果存入 `_result` 列表
- 空数据时 `_result = []`
- `_result` 的顺序与查询条件中的指标列表顺序一致
- 不要写 `if __name__` 块

## 错误修复

如果代码执行报错，你会收到错误信息。分析错误原因并修正代码重新生成。
