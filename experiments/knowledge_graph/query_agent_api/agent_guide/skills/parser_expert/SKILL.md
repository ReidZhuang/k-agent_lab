## 关于 var（指标）的提取要点

var 是用户 query 中要查询的核心指标，它必须且只能有一个值。

**常见指标举例：**
- 量价类：涨跌幅、成交量、成交额、换手率、振幅、开盘价、收盘价、最高价、最低价
- 估值类：PE、PB、PE_TTM、市值、市盈率
- 财务类：毛利率、净利率、营业收入、净利润、每股收益
- 资金类：资金流向、主力净流入、北向资金
- 市场类：市场热度、情绪指数
- 板块类：板块涨跌幅、板块排名

**提取技巧：**
- "涨跌幅"本身是 imprecise 表达 → 不需要"个股涨跌幅"或"板块涨跌幅"作为 var（留给下游路由判断），var 保持原始语义："涨跌幅"
- "最近的毛利率" → var: "毛利率"，condition: ["最近一期"]
- "A股的PE" → var: "PE"

## 关于 obj（主体）的提取要点

obj 是取数的对象，可能有多个（同一指标下的多个主体并列）。

**常见主体类型：**
- 个股：宁德时代、贵州茅台、300750.SZ
- 板块/行业：电池板块、新能源汽车、白酒行业
- 指数：上证指数、沪深300、创业板指
- 市场：A股、港股、美股
- 资金：北向资金、主力资金

**提取技巧：**
- 股票代码格式（如 300750.SZ）→ 直接作为 obj
- 模糊指代（"茅台"→ "贵州茅台" 或 "茅台"）→ 保持原文
- 如果某个金融概念（如"换手率"）的查询对象不需要特定主体，obj 可为该概念本身

## 关于 condition（条件）的提取要点

condition 是取数的范围/限制条件，可以有多个。

**常见条件：**
- 时间：今天、昨天、本周、本月、今年以来、最近N天、最近一个季度、上年同期
- 区间：收盘价、开盘价、盘中
- 限定："宁德时代所在的板块"、"深交所上市的"

**时间默认规则：**
- 没有明确时间条件 → condition 含 ["今天"]
- "最近" + 数字 + 时间单位 → "最近5天"、"最近3个月"
