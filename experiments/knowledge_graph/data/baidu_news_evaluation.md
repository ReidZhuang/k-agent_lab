- 搜索关键词: 光刻机、光刻、芯片、半导体、集成电路

近半年 826 条数据中**没有任何一条**与光刻机/芯片/半导体相关。

## 数据内容性质

全部数据都是**经济数据发布日历**，不是新闻。典型条目：

| 日期 | 地区 | 事件 |
|:---|:---|:---|
| 2026-06-30 | 美国 | 美国5月核心PCE物价指数年率 |
| 2026-06-30 | 中国 | 中国6月官方制造业PMI |
| 2026-06-30 | 中国 | 中国6月财新制造业PMI |
| 2026-06-30 | 美国 | 美国6月密歇根大学消费者信心指数终值 |
| 2026-05-21 | 美国 | 美国5月Markit制造业PMI初值 |
| 2026-05-21 | 美国 | 美国截至5月16日当周初请失业金人数 |
| 2026-04-21 | 中国 | 中国4月一年期贷款市场报价利率 |
| 2026-04-21 | 中国 | 中国4月五年期贷款市场报价利率 |
| 2026-03-12 | 美国 | 美国2月CPI年率未季调 |
| 2026-01-01 | 全球 | 元旦假期各国休市安排 |

## 结论

**不适合搜索"光刻机"这类产业新闻。** 这个数据源是经济日历（类似财经日历app），只包含各国经济指标（GDP/CPI/PMI/利率/就业等）的发布时间和公布值。它的用途是"今天有什么经济数据要发布"，不是产业新闻资讯。

2. akshare 的新闻接口（如有）待确认
