# DS_TUSHARE_DAILY 字段映射

| 字段名 | 类型 | 说明 |
|--------|:----:|:-----|
| open | float | 当日开盘价 |
| vol | float | 成交量（手） |
| trade_date | date | K线交易日期 |
| close | float | 当日收盘价 |
| pct_chg | float | 涨跌幅百分比 |
| pre_close | float | 前收盘价（除权价） |
| change | float | 涨跌金额 |
| amount | float | 成交额（千元） |
| low | float | 当日最低价 |
| high | float | 当日最高价 |
