# DS_AKSHARE_SECTOR_THS — 同花顺板块行情（THS Sector）

## 数据源名称
- **中文名称**：同花顺板块行情
- **英文名称**：THS Sector
- **数据源ID**：DS_AKSHARE_SECTOR_THS

## 接口
- **类型**：akshare SDK（B类）
- **函数签名**：`ak.stock_board_industry_summary_ths()`

## 数据内容描述
同花顺行业板块实时行情汇总

## 数据内容覆盖业务描述
板块行情对比

## 数据接口背景描述（若有）
AkShare 是一个开源金融数据接口库，支持多种财经数据源。本接口通过 AkShare SDK 获取数据，免费使用。建议安装最新版 `pip install akshare --upgrade`。

## 数据接口函数调用方法描述
### 基本使用方法
```python
import akshare as ak
df = ak.stock_board_industry_summary_ths()
```
