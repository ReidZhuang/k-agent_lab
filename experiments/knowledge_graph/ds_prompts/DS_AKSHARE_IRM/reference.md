# DS_AKSHARE_IRM — 互动易问答（IRM Q&A）

## 数据源名称
- **中文名称**：互动易问答
- **英文名称**：IRM Q&A
- **数据源ID**：DS_AKSHARE_IRM

## 接口
- **类型**：akshare SDK（B类）
- **函数签名**：`ak.stock_irm_cninfo(symbol)`

## 数据内容描述
深交所互动易平台投资者问答记录

## 数据内容覆盖业务描述
投资者关系、舆情分析

## 数据接口背景描述（若有）
AkShare 是一个开源金融数据接口库，支持多种财经数据源。本接口通过 AkShare SDK 获取数据，免费使用。建议安装最新版 `pip install akshare --upgrade`。

## 数据接口函数调用方法描述
### 基本使用方法
```python
import akshare as ak
df = ak.stock_irm_cninfo(symbol)
```

### 输入参数
| 参数名 | 必填 | 类型 | 说明 |
|:------|:----:|:----:|:-----|

### 返回值
['股票代码', '公司简称', '行业', '行业代码', '问题', '提问者', '来源', '提问时间', '更新时间', '提问者编号', '问题编号', '回答ID', '回答内容', '回答者']

### 重要约定
- symbol 参数不要带 .SZ / .SH 后缀，只传纯数字代码
- 有的股票可能没有互动易数据（会报错），选择有数据的股票测试
- 返回数据按时间倒序（最新在前）
- **如果提取"回答内容"且最新行的回答为空（None），则跳过该行继续往下找非空的行**
- 如果提取"问题"则直接用第一行（最新提问）
- 列名有中文含空格，用 row["列名"] 提取即可

## 数据更新时效描述
AkShare 数据源多样，更新频率取决于底层源。实时行情类盘中高频更新，财报/机构持仓类按季度更新。部分接口数据延迟约 15-30 分钟。
