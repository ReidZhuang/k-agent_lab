## 字段映射

| cash_from_sales | float | 销售商品收到现金 | 销售商品、提供劳务收到的现金 |

| inv_cash_flow | float | 投资活动现金流净额 | 投资活动产生的现金流量净额 |
| fin_cash_flow | float | 筹资活动现金流净额 | 筹资活动产生的现金流量净额 |

| cash_for_invest | float | 投资所支付的现金 | 投资所支付的现金 |
| cash_for_fixed_asset | float | 购建固定资产付现 | 购建固定资产、无形资产和其他长期资产所支付的现金 |
| cash_net_increase | float | 现金净增加额 | 现金及现金等价物净增加额 |
| cash_begin | float | 期初现金 | 期初现金及现金等价物余额 |
| cash_end | float | 期末现金 | 期末现金及现金等价物余额 |
