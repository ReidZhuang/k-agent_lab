# DS_TUSHARE_INDEX_DAILY 字段映射

| 字段名 | 类型 | 说明 |
|--------|:----:|:-----|
| swing | float | 指数当日振幅 |
| amount | float | 指数成交额（千元） |
| vol | float | 指数成交量（手） |
| pre_close | float | 前一交易日收盘点位 |
| open | float | 当日开盘点位 |
| low | float | 当日最低点位 |
| high | float | 当日最高点位 |
| change | float | 指数涨跌点数 |
| pct_chg | float | 指数涨跌幅百分比 |
| close | float | 指数收盘点位 |
