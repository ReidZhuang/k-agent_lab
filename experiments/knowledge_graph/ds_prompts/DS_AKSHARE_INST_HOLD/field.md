## 字段映射
| 字段名 | 类型 | 说明 |
|--------|:----:|:-----|
| 持股比例 | float | 机构持仓占A股比例（%） |
| 最新持股比例 | float | 最新一期持股比例（%） |
| 持股数 | float | 持仓股数（万股） |
| 最新持股数 | float | 最新一期持仓股数（万股） |
| 占流通股比例 | float | 占流通A股比例（%） |
| 最新占流通股比例 | float | 最新一期占流通A股比例（%） |
| 持股比例增幅 | float | 持股比例较上季度变动（百分点） |
| 占流通股比例增幅 | float | 占流通股比例较上季度变动（百分点） |
