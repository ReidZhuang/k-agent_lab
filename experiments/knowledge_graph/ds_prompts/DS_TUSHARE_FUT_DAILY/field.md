# DS_TUSHARE_FUT_DAILY 字段映射

| 字段名 | 类型 | 说明 |
|--------|:----:|:-----|
| vol | float | 成交量（手） |
| trade_date | date | 交易日 |
| amount | float | 成交金额（万元） |
| settle | float | 当日结算价 |
| change2 | float | 结算价-昨结算价 |
| oi_chg | float | 持仓量变化 |
| ts_code | string | 期货合约TS代码 |
| high | float | 当日最高价 |
| open | float | 当日开盘价 |
| change1 | float | 收盘价-昨结算价 |
| close | float | 当日收盘价 |
| pre_close | float | 昨日收盘价 |
| pre_settle | float | 昨日结算价 |
| oi | float | 持仓量（手） |
| low | float | 当日最低价 |
