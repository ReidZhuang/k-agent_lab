## 开源 Python 库推荐（封装了上述数据源）

| 库名 | 特点 | 免费情况 | 适用建议 |
| :--- | :--- | :--- | :--- |
| **AkShare** | 封装了东方财富、新浪等数据源，接口丰富 | 完全免费、开源 | **首推**。适合快速原型开发，但需注意爬虫稳定性。 |
| **Tushare** | 标准化API，数据质量较高 | 积分制，基础功能免费 | 适合需要一定数据质量的中小型项目。 |
| **Baostock** | 无需注册，提供准确的历史行情和财务数据 | 完全免费 | 适合历史回测，但一次只能获取单只股票的单季度财报。 |

## 构建 Agent 的路径建议

1. **快速原型**：使用 **AkShare** 或 **新浪/腾讯免费接口**，零成本验证逻辑。
2. **追求稳定**：考虑 **证券之星**（每日500次免费）或 **聚合数据** 等官方 API。
3. **商业化/专业级**：再评估 **同花顺 iFinD** 或 **Wind** 等付费服务。

> ⚠️ **注意**：使用爬虫方式时，请合理控制请求频率，做好 IP 轮换等防封策略，并留意数据使用合规性。
